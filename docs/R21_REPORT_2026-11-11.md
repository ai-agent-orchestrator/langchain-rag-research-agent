# R21 — 도메인 무관 평가 러너

## 구현

- `scripts/domain_eval.py`: JSON 팩 로딩, 선언형 포함·금지·개수 지표,
  사전 키 기반 대상 필드, 문항별 기대값, 실행기 주입 인터페이스를 구현했다.
  팩의 Python 코드는 실행하지 않는다. 모델·네트워크·저장소 생성도 하지 않는다.
- 품질은 지표별 성공 수·표본 수·비율·Wilson 95% 구간과 지표 평균으로 집계한다.
  안전 지표는 실패 문항 수·표본 수·위반률·Wilson 95% 구간·상한·원시 개수를
  별도 집계하며 품질 평균에 넣지 않는다. injection은 품질 분모에서 제외한다.
  빈 기대값은 분모에서 제외하고, 빈 팩·빈 split·누락 필드·중복 ID는 오류로 처리한다.
- 결과는 `.runs/domain_eval/<domain>/runs.jsonl`에 누적한다.
  원문 출력은 저장하지 않고 문항 ID와 집계만 기록한다.
- research는 기존 `evals/research/cases.ko.json`을 읽는 내장 어댑터다.
  실제 `ResearchRunner`와 `keyword_search`를 사용한다. 합성 규칙 경로 시험이며
  실제 모델 결과가 아니다. 기존 `scripts/research_eval.py`와 기본 서비스 설정은 보존했다.
- `evals/domains/README.md`에 스키마·집계 의미·사용법을 기록했다.
  `tests/test_domain_eval.py`는 작은 합성 팩 2종과 실제 리서치 어댑터를 시험한다.

## 설계 대비 차이

설계 정본의 도메인 교체 경계에 맞춰 일반 평가부는 JSON과 실행기 함수만 받는다.
리서치 실행기만 rag 구현을 지연 import한다. LangChain/LangGraph 직접 import나
새 src 모듈 간 의존성은 추가하지 않았다. MATURITY는 incubating이다.

허용 파일 네 개를 지키기 위해 research 팩의 cases.json/metrics.json을 별도 생성하지 않고
기존 문항과 선언형 지표 사전을 읽는 내장 등록으로 구현했다. 폴더 JSON 등록은 후속 연결 필요다.
일반 팩은 지정된 cases.json/metrics.json 형식을 그대로 사용한다.

리서치 수치 정답은 본문 안의 이름·값 부분 문자열 그룹으로 변환한다.
기존 research_eval의 같은 문장·숫자 토큰 검사와 동일한 점수를 보장하지 않는다.
인과·조건·균형은 정답 표현 포함으로 검사한다. 새 결과를 기존 실험과 직접 비교하면 안 된다.

CLI는 compare만 실행하며 설정 자동 선택·confirm 실행·보드 갱신을 추가하지 않았다.
설정 선택과 선택된 한 설정에 대한 confirm 일회성 영속 관리는 후속 연결 필요다.
순수 evaluate 함수의 split 인자는 호출자가 별도 선택 절차를 관리하는 용도다.
유사도 검색·버전 발행·롤백·manifest를 구현하지 않았으며 memvid는 import하지 않는다.

## 미검증

새 시험의 실행 통과, 실제 모델·실제 Chroma의 검색 품질, 동의어·의미 단위 평가,
팩 간 점수 비교 가능성은 미검증이다. 모델이 필요한 구현은 추가하지 않았으므로
실제 모델 실행 명령도 이 작업에는 없다. 모델을 쓰는 호출자는 마스킹을 완료한 실행기를
주입해야 한다. 제공 출력의 개인정보를 러너가 자동 마스킹하지 않는다.

## 커밋 제한

현재 브랜치에서 아래 명령을 시도했으나 두 명령 모두
`fatal: Unable to create 'C:/work/rra-codex/.git/index.lock': Permission denied`로 실패했다.
샌드박스의 `.git` 읽기 전용 제한 때문에 새 커밋 해시는 없고 네 파일은 untracked로 보존했다.
미커밋 변경 없이 마무리하는 요구는 이 환경에서 이행하지 못했다.
NightCoder가 쓰기 가능한 환경에서 아래 네 파일을 단일 커밋으로 수집해야 한다.

```powershell
git add -- scripts/domain_eval.py evals/domains/README.md tests/test_domain_eval.py docs/R21_REPORT_2026-11-11.md
git commit -m "feat: add data-defined domain evaluation runner (R21)"
```

push와 원격·브랜치 설정 변경은 하지 않았다. 작업 파일을 삭제하거나 보호 설정을 우회하지 않았다.
