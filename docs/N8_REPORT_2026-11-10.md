# N8: 비식별 로컬 메트릭 기록기

2026-11-10 KST. NightCoder 레인, 현재 저장소·브랜치 `nc/rra-codex`에서 작업.

## 구현

`observe/metrics.py`에 stdlib와 core 계약만 사용하는 `MATURITY = "incubating"`
모듈을 추가했다. 기존 모듈·시험·KNOWN_DEBT는 수정하지 않았다.

- `LocalMetrics().record(**event)`는 메모리에 기록한다.
  `LocalMetrics(".runs/metrics.jsonl")`는 같은 이벤트를 JSONL에 append한다.
  기존 파일의 이벤트는 자동으로 메모리에 읽지 않는다.
  `LocalMetrics.from_jsonl(path)`는 모든 줄을 재검증해 메모리에 복원한다.
- 필수 허용 키는 `stage`, `latency_ms`, `status`, `input_length`,
  `output_length`, `slots_occupied` 6개뿐이다. 추가·누락 키는 오류다.
  단계는 retrieve/grade/generate/answer, 판정은 기존 `RetrievalStatus`·`Status`,
  `RETRIEVAL_UNAVAILABLE`, `INFERENCE_TIMEOUT`, `GENERATION_CAPACITY_EXCEEDED`와
  작업 명세의 ANSWERED/UNAVAILABLE로 제한한다. 원문을 임의의 판정 문자열에
  넣는 것도 거부한다. 오류 메시지에 거절한 키·값을 포함하지 않는다.
- 지연은 유한한 음이 아닌 수, 길이·슬롯 점유는 음이 아닌 정수만 받는다.
  bool은 수치로 허용하지 않는다. 호출자가 문자열 대신 길이를 계산해 전달한다.
  저장 파일 경로는 현재 작업 디렉터리의 `.runs/` 내부로 제한한다.
  읽기에도 같은 경로 제한을 적용한다.
- `.summary()` / `summarize(events)`는 단계별 count/p50_ms/p95_ms,
  판정별 건수, timeout 건수·분모·비율·Wilson 95% 구간을 반환한다.
  분위수는 정렬된 표본의 `(n-1)*q` 위치에서 선형 보간한다.
  timeout은 `status == INFERENCE_TIMEOUT`인 이벤트다. 요청 단위가 아닌
  이벤트 단위 비율이므로 여러 단계 이벤트를 기록할 때 분모에 유의해야 한다.
  빈 단계의 분위수와 빈 표본의 비율·구간은 null이다.
- 반환 이벤트·조회 스냅샷은 복사본이므로 외부 변경이 내부 기록을 바꾸지 않는다.
  디스크 기록 실패 시 메모리에 해당 이벤트를 추가하지 않는다.

`observe/local_log.py`와는 허용 목록·JSONL append라는 구조가 같다. 기존 기록기는
state에서 해시·segment ID·레이블·버전을 추출하며 이번 수치 전용 스키마와 다르다.
기존 함수를 재사용하면 원문 포함 state를 받아야 하므로 호출하거나 수정하지 않았다.
tracing.py도 수정하지 않았고 파이프라인에 연결하지 않았다.

후속 연결 필요: `rag/` 조립부에서 retrieve/grade/generate/answer의 시작·종료를
`perf_counter`로 측정하고 완료·예외 판정을 허용 상태로 매핑해 기록할 수 있다.
길이는 해당 단계 경계에서 산출하고, 슬롯 점유는 실제 worker의 상태를 읽어 전달한다.
예외 메시지·질의·문서·state 자체는 전달하지 않는다. 이 연결은 이번 범위 밖이다.

## 보호 범위 및 미검증

착수 시 작업 트리는 깨끗했다. 기존 추적 파일 359개(.env 계열 제외)의
작업 전후 SHA-256은 모두 동일했다. 증거는 `.runs/n8/tracked-before.json`과
`.runs/n8/tracked-after.json`이다. data/profiles/frozen masking과 기존 시험,
금지 모듈을 수정하지 않았다. 보호 파일 18개의 별도 기준 manifest는 찾지 못해
외부 기준에 따른 정확한 18개 개별 대조는 미검증이다. 모든 기존 추적 파일의
작업 전후 해시 비교에 data/profiles와 guard/masking.py가 포함되어 있다.

실제 실행·구조 시험 통과·운영 성능·파이프라인 연결은 미검증이다.
단일 소유 스레드용 기록기이며 동시 writer 조정, 파일 회전·보존 정책,
프로세스 중단 시 쓰기 원자성은 구현하지 않았다.
모델·LLM·임베더 평가를 수행하지 않았고 해당 평가를 위한 연결도 추가하지 않았다.
저장소 구현을 사용하지 않아 memvid 의존성이나 Chroma 대체 기능도 추가하지 않았다.
push·원격/브랜치 설정 변경·네트워크 호출·새 패키지 설치는 하지 않았다.

## 커밋 차단

지정한 3개 파일을 대상으로 한 `git add`가
`fatal: Unable to create 'C:/work/rra-codex/.git/index.lock': Permission denied`로
차단됐다. 샌드박스에서 `.git`은 읽기 전용이고 권한 상승은 허용되지 않는다.
`git commit -m "feat: add strict local numeric metrics recorder"`도 같은
index.lock 권한 오류로 실패했다. 새 커밋 해시는 없으며 기존 HEAD는 `2c0afac`이다.
작업 파일은 보존한다. 커밋과 깨끗한 작업 트리 요구는 이 권한 제한으로
완료하지 못했다.
