모델별 JSON 및 Markdown/어두운 HTML 비교표. 데이터 v1은 기존 로더와 split 부여 사용.

색인 생성→검색→보정→파일 흐름을 검증했다. 준비 안 된 모델은 미준비로 표시한다.

τ_high는 기존 보정기의 근거 없음 오수용 0 제약 및 보수적 동점 처리 결과다.
동점 분리가 안 되면 근거 있는 항목도 거절하거나 1 초과 임계값이 될 수 있다.
confirm은 보정에 사용하지 않는다. 근거 없음 표본이 0이면 오수용 0 보장 불가.
합성 소규모 골든셋, 통계적 결론 아님. 실제 Chroma/E5/BGE 성능은 미검증.
