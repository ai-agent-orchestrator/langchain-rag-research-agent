# E4 질의 지시문 효과

두 평가 진입점에 `--instruction none|default|custom:<text>`를 추가했다. 문서 인코딩은 바꾸지 않는다. E5 default는 기존 Instruct/Query, none은 접두어 제거, custom은 지정 지시문이다. BGE-M3는 모든 설정에서 무접두어 대조군이다. fake는 경로 시험 열, 실제 모델은 별도 열로 표기한다.

Recall@3는 복수 정답의 비율이며 Hit@3와 구분한다. MRR 및 정답 최대 점수 평균−근거 없음 top1 평균 간격을 같은 표에 낸다. 두 집단 중 하나가 없으면 간격은 null이다. v2는 quote가 포함된 청크만 정답 점수로 인정하며 injection은 분모에서 제외한다. 원시 점수는 모델 사이에 공통 척도로 가정하지 않는다. v1 보정은 compare만 사용하고 confirm은 별도 보고한다.

실제 모델은 실행하지 않았다. 준비된 로컬 캐시에서 대표가 실행할 명령:

```powershell
foreach ($i in @('none','default','custom:Retrieve relevant legal passages')) {
  $tag = $i.Split(':')[0]
  .\.venv\Scripts\python.exe scripts/compare_embedders.py --models e5 bge-m3 --instruction "$i" --out ".runs/e4/$tag"
  .\.venv\Scripts\python.exe scripts/eval_retrieval_v2.py --set data/golden_retrieval/terms_v2.json --embedder e5 --split compare --instruction "$i" --out ".runs/e4/v2-$tag"
}
```

전체 시험 최종: `238 passed, 5 skipped` (26.99s)。初回は新規 observe モジュールの maturity 宣言が配置規則に合わず 1 failed / 237 passed。宣言のみを既存 observe と同じ incubating に合わせた。既存試験は変更していない。実モデル未実行。
