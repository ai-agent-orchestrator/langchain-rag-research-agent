# E6 근거 없음 판정 경계

저장된 E4/E5 evaluation_rows를 입력받아 τ_abs × τ_gap 격자를 compare 문항에만 적용한다. 각 점의 오수용과 오거절은 errors/n, 비율, Wilson 95% 구간을 함께 기록한다. HTML은 abs에 따른 곡선을 gap별로 그리고 Wilson 오차막대와 hover 수치를 제공한다. confirm은 곡선과 선택에서 제외하고, compare에서 고른 한 조합에만 적용한다. 선택 목적은 오수용률 최소, 오거절률 최소, 높은 임계값 순으로 사전에 고정했다. 양성/음성 compare 표본 중 하나가 없으면 선택하지 않는다.

injection은 검색 품질 분모에서 제외한다. 9개 전체 근거 없음 표본도 compare/confirm으로 나누면 각각 더 작다. 0/9 오수용의 Wilson 상한도 약 29.9%이며 0건은 보장이 아니다. 격자의 구간은 개별 점의 명목 구간이며, 다중 탐색이나 선택에 대한 보정 구간이 아니다. confirm 결과를 보고 임계값을 재선택하면 안 된다.

실제 모델 미실행. 대표 실행 명령 (먼저 E4 모델 평가 결과 필요):

```powershell
.\.venv\Scripts\python.exe scripts/sweep_retrieval_gates.py --input .runs/e4/default/calibration/e5.json --tau-abs 0 .2 .4 .6 .8 1 --tau-gap 0 .05 .1 .2 --out .runs/e6/e5
```

fake 경로 시험과 실제 모델은 JSON/표의 별도 열로 유지한다. 기존 골든셋/시험/프로필은 변경하지 않았다.

전체 시험: `240 passed, 1 failed, 5 skipped` (25.98s). 기존 `tests/test_index_lifecycle.py::test_versions_rollback_and_prune`가 memvid 쓰기 MemvidError → RetrievalUnavailable로 실패했다. 수정/재시도하지 않았다. 새 Wilson/격자/보고서 시험은 통과했다. confirm 점수를 바꿔도 선택 임계값이 같음을 확인했다. 실제 모델 결과는 없다.
