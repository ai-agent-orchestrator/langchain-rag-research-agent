# R42 구조화 채점기 슬롯

## 구현

- `rag/graders.py`: strict Pydantic `RelevanceGrade`, `GroundedGrade` 및 문자열 질문·문서·답변과 문자열 tuple 근거를 받는 `Grader` 프로토콜을 추가했다. MATURITY는 incubating이다.
- `RuleGrader`는 기존 research_filter의 내용어 추출과 ResearchFilter 검수 규칙을 감싼다. 관련성은 내용어 교집합이며 근거성은 NO_EVIDENCE, EMPTY_ANSWER, UNSUPPORTED_NUMBER, UNGROUNDED_SENTENCE만 판정한다. 스타일·커버리지 검수는 기존 verify_report가 담당한다.
- `FakeLLMGrader`는 명시적인 유한 응답 큐를 사용한다. 큐 소진은 오류이며 응답을 복사해 반환한다. `StructuredLLMGrader`는 호출자가 주입한 모델의 with_structured_output을 사용한다. masker가 필수이고 모든 입력을 마스킹한다. DATA를 JSON으로 구분하고 태그 문자를 escape하며 기존 serving_trace_guard/config를 사용한다. 스키마 오류·모델 오류는 전파하며 승인으로 대체하지 않는다.
- `ResearchConfig.grader=None`이 기본이다. 지정한 경우 refine 진입 시 pending 문서의 관련성을 판정하고 통과 문서만 정제·추출한다. 기본 검색, 병렬 검색 합류, gap 검색 모두 같은 경로를 거친다.
- verify에서 기존 검수 코드와 근거성 실패 코드 `UNGROUNDED:<reason>`을 합친다. 기존 rewrite 한도·허용 코드·비용·종료 유형 판정을 재사용한다. 사유는 공백 정규화 후 160자로 요약하며 빈 실패 사유는 UNSPECIFIED이다. RELEVANCE 및 GROUNDED 로그에 판정과 사유를 남긴다.
- 탈락 문서는 sources의 검색 이력으로 보존되지만 claims에는 들어가지 않는다. 채점 근거는 span 검증을 통과한 claims의 텍스트뿐이다. 시스템 note·인용 표시는 답변 근거성 입력에서 제외한다.

검증 항목: 기본값과 명시적 None의 결과 동일성, 무관 문서 배제, 사유 로그, 근거성 실패 후 rewrite와 통과, 지속 실패의 give_up, 사유 길이, 전부 탈락, gap 검색 채점, 순차/병렬 검색·추출 및 체크포인트 조합, 기존 규칙 래핑, fake 큐 소진/복사, 구조화 모델 schema/dict 반환, 입력 마스킹 경로·DATA 경계, 잘못된 출력 거절, masker 필수 조건이다. 실행 통과는 미검증이다.

## 설계 대비 차이

AGENTS.md, METRICS_BOARD.ko.md, RESEARCH_GRAPH_DESIGN.ko.md, DOMAIN_FILTERS.ko.md, LANGGRAPH_GUARDRAIL.ko.md와 test_structure.py 규칙을 확인했다. 채점 슬롯은 rag 안에 있고 기존 core 계약을 사용하며 KNOWN_DEBT를 늘리지 않았다. 저장소·memvid 경로 변경은 없다.

## 미검증 및 보호 확인

실제 모델 호출·다운로드·네트워크·LangSmith 업로드를 수행하지 않았다. 실제 모델 품질, 바꿔 말하기·한국어 조사에 따른 관련성 오탐, 프롬프트 주입 저항성, 비용·지연은 **미검증**이다. reason은 호출자가 마스킹된 출력으로 제공해야 하며 출력 개인정보 검증 기능을 새로 추가하지 않았다. unsupported는 채점 결과에 제공하며 별도 보드 span 이벤트로 연결하지 않았다.

대표의 로컬 모델 구성 후 수동 실행 진입 명령(이 환경에서는 실행하지 않음):

```powershell
python -i -c "from rag_research_agent.rag.graders import StructuredLLMGrader; from rag_research_agent.rag.research_graph import ResearchConfig, ResearchRunner"
```
