# R45 — 프롬프트 인젝션 유형별 적대 세트와 입력 검사

## 구현

`guard/injection_check.py`에 독립적인 공개 함수 `check_user_input(text)`와
`check_passage(text)`를 추가했다. 반환값은 불변 `InjectionDecision`이며
`allowed`, `code`, `evidence`, `span`을 제공한다. 통과 시 코드는 빈 문자열이고
차단 시 `INJECTION:direct_override|role_spoofing|indirect|encoding|exfiltration`이다.
여러 규칙이 맞으면 문서 지시 → 역할 사칭 → 유출 요구 → 직접 무시 순으로 판정한다.
정규화·디코딩이 탐지에 필요하면 `encoding` 코드가 우선한다.

NFKD 정규화, 대소문자 통합, 공백·구두점·제로폭 문자 제거, 정규 분해 한글 자모,
단일 단계 URL percent 및 HTML entity 디코딩을 지원한다. 정규화 문자와 원문 위치를
매핑하여 근거 구절이 원문 슬라이스와 일치하도록 했다. 호환 자모의 임의 초성/종성
재해석, base64, 중첩 인코딩은 지원 범위 밖이다.

검색 문단은 별도로 답변·인용 조작을 검사한다. 사용자 입력에서는 한정된 형식의
인용 문구 분석·번역 요청을 허용하지만 검색 문단에는 이 예외를 적용하지 않는다.
임의의 '보안 연구' 키워드가 있다고 통과시키지 않는다. 이 규칙은 의미 이해나
인젝션 방어를 보장하지 않는다.

근거는 호출자에게만 반환하고 자동 기록하지 않는다. repr에서도 근거를 제외한다.
호출자는 마스킹된 텍스트를 전달하고 State·이벤트에는 코드만 남겨야 한다.
도메인 필터에서는 결과의 `allowed`·`code`를 기존 `InputDecision`에 전달할 수 있다.
자동 등록·기본 설정·기존 `check_input`·기존 refine 경로는 변경하지 않았다.

`evals/adversarial/injection.ko.json`에는 한국어 합성 문항 42개를 담았다.
공격 5종 각 6개와 과차단 확인용 정상 문항 12개이며 정상 문항은 `expected=pass`다.
각 문항에 고유 영문 ID, 유형, user/passage 표면, 기대 판정을 명시했다.
전체가 compare 자료이며 설정 선택·튜닝·confirm 적용은 수행하지 않았다.
이 자료는 검색 품질 평가 분모에서 제외한다. 개인정보 모양의 값은 사용하지 않았다.

## 시험

`tests/test_injection_check.py`에 매개변수 확장 기준 67개 시험을 작성했다.
실제 공개 함수로 42문항의 탐지·통과·코드·원문 위치를 확인하며 정규화 8사례,
빈 입력·정상 문구·잘못된 인코딩, 비문자 입력, 인용 분석 예외 뒤 공격 추가,
문단 전용 조작, 실제 ResearchFilter 기본 동작 불변과 InputDecision 호환을 검사한다.
모델·임베더·저장소 대역은 사용하지 않았다.

실제 함수를 호출해 유형별 탐지율·과차단률과 표본 수 및 Wilson 95% 구간을
`.runs/r45/metrics.json`으로 쓰는 시험도 포함했다. 기대값을 실측치로 복사하지 않는다.

전체 시험 명령 `python -m pytest -q`와 `py -m pytest -q`를 시도했으나 두 실행기를
모두 찾을 수 없어 수집·실행이 시작되지 않았다.

**tests not run here: Python and py executables are unavailable in this sandbox.**

## 설계 대비 차이

설계의 screen 및 refine에서 사용할 수 있는 검사 경계를 제공했다. 변경 허용 범위가
네 파일이므로 실제 도메인/그래프 연결, 옵션 설정 노출은 **후속 연결 필요**다.
계측 보드의 `guard[].code`에 사용할 코드를 제공하되 이벤트 생성·`end_type` 매핑은
호출자 책임으로 남겼다. 기존 경로의 종료 유형을 바꾸지 않았다.

체크포인터/thread, interrupt 승인, 관련성 재작성 루프, 근거성 검사 및 LLM-as-judge는
이번 인젝션 검사 범위에서 구현·변경하지 않았다. 모델 호출이 필요하지 않으므로
모델 인터페이스나 fake 모델을 추가하지 않았다. 실제 모델 실행 명령도 해당하지 않는다.
MATURITY는 incubating이며 표준 라이브러리만 사용하고 모듈 간 의존성 및 KNOWN_DEBT를
늘리지 않았다. Chroma/memvid 구현은 건드리지 않았다.

## 미검증 및 마무리

Python 구문·전체 시험·실제 탐지 수치는 런타임 부재로 미검증이다. 문장 부정·반어·
우회 표현의 일반적 의미 판정, 인용 예외 악용, 실제 검색 문서 품질도 미검증이다.
원문 근거는 민감할 수 있으므로 자동 저장하지 않으며 외부 업로드 경로도 없다.

초기 작업 트리는 깨끗했다. 지정 신규 네 파일만 변경했으며 기존 시험·금지 파일·
README·data·profiles는 수정하지 않았다. 네트워크·모델·다운로드·패키지 설치·비밀값
조회는 수행하지 않았다. 현재 브랜치를 유지하고 push·원격 설정 변경은 하지 않았다.

정적 점검: JSON 문항 42개·유형별 개수·고유 ID, 신규 네 파일의 줄 끝 공백 없음,
`git diff --check` 통과, 보호 파일 SHA-256 **18/18 동일**을 확인했다.
신규 파일은 untracked이므로 공백은 파일 내용을 별도로 검사했다.

커밋 차단: 지정 네 파일의 `git add -- ...`가
`Unable to create 'C:/work/rra-codex/.git/index.lock': Permission denied`로 실패했다.
이 환경의 `.git`은 읽기 전용이고 승인 정책은 never이므로 권한을 우회하거나
승격을 요청하지 않았다. 커밋 해시는 없음. 구현은 삭제하지 않고 보존했으며
지정 네 신규 파일이 미커밋 상태다. 커밋·깨끗한 작업 트리 요구는 이 제약으로
이행하지 못했다. 쓰기 가능한 NightCoder 환경에서 stage/commit이 필요하다.
