# R44 근거성 검사기 단독 평가

## 구현

지정된 네 파일만 추가했다. `scripts/groundedness_eval.py`는 그래프를 만들거나 실행하지 않고 실제 `verify_report(check_claim_alignment=True)`와 R42 `Grader.grade_grounded`를 호출한다. 근거 문단은 실제 `Claim`의 전체 문단 span으로, 답변은 명시적 claim 인용을 가진 실제 `Draft`/`ReportSentence`로 구성한다. 규칙 검증 또는 채점기 중 하나라도 거절하면 block이다. 기본 서비스 설정과 기존 검사기는 변경하지 않았다. Chroma/memvid 저장소와 임베더를 사용하지 않는다.

데이터는 한국어 합성 40쌍이다. 정상 15개, 오류 25개(없는 수치 5, 수치 변조 5, 없는 조문 4, 인과 단정 4, 한쪽 근거만 4, 인용 없는 문장 3)다. 법령은 가상 규정이며 개인정보는 넣지 않았다. 각 문항은 `expected`, `fault_type`, 근거 문단, 문장별 인용이 있는 답변을 포함한다. 유형·정답·ID 중복·문단·문장 구조를 판정 전에 검사한다. 없는 인용 ID는 검사기에서 UNCITED로 판정할 수 있도록 허용한다.

오류 탐지율은 block 문항 중 실제 차단 비율, 과차단률은 pass 문항 중 실제 차단 비율이다. 유형별 탐지율도 오류 문항만 분모로 삼는다. 모든 비율에 count/n/rate/Wilson 95%를 기록한다. 빈 분모는 rate와 구간을 null로 남긴다. 탐지 0건 또는 과차단 0건은 보장을 뜻하지 않는다.

`--grader rule`은 실제 R42 RuleGrader다. `--grader fake`는 실제 FakeLLMGrader에 정답과 무관한 고정 승인 응답을 주입한다. 두 모드 모두 규칙 verify를 실행하며 fake 결과는 `fake_path_test` 경로 시험으로 분리한다. fake 탐지율은 모델 성능이 아니다. 라이브러리 함수 `evaluate(cases, grader)`는 호출자가 채점기를 주입할 수 있다. 채점 오류·응답 고갈은 전파하며 완료 전 결과는 기록하지 않는다.

결과는 `.runs/groundedness/runs.jsonl`에 실행별 추가된다. 실행 ID, UTC 시각, git SHA, 데이터 SHA-256, 모드, 지표, 문항별 코드와 채점 응답을 기록한다. 그래프 비실행과 모델 호출 0회를 명시한다. 문항별 end_type은 통과 END / 차단 give_up이다. 전체 평가 실행은 두 종료 유형을 포함하므로 run 전체에 단일 end_type을 붙이지 않았다.

## 시험

`tests/test_groundedness_eval.py`에 매개변수 확장 기준 14개 시험을 작성했다. 실제 검사기/R42 클래스, 작은 fake 세트의 탐지·과차단·유형별 집계와 Wilson 수치, 빈 세트, 숫자 변조, 인용 누락, 반대 근거 누락, fake 승인으로 규칙 차단을 뒤집지 못함, 응답 고갈, 잘못된 데이터, 정답 비참조, 40개 데이터 구성과 실제 호출, CLI JSONL 누적·모드 구분을 다룬다. CLI 시험의 결과 파일도 `.runs/`에만 쓴다. 기존 시험은 변경하지 않았다.

전체 시험 명령 `python -m pytest -q`를 시도했으나 Python 실행 파일을 찾지 못했다. `py`도 사용할 수 없다.

**tests not run here: Python and py executables are unavailable in this sandbox.**

이 환경에서 시험 미실행: Python 실행기 없음. 최종 시험 집계: passed/failed/error/skipped 모두 미집계(수집·실행 시작 불가). memvid 시험도 실행하지 않았고 수정·skip·기대값 변경을 추가하지 않았다. NightCoder 게이트가 전체 시험을 판정해야 한다.

PowerShell JSON 파싱으로 40개와 유형별 개수를 확인했다. 신규 파일은 untracked라 `git diff --check`의 대상에 포함되지 않아 네 파일의 trailing whitespace를 별도로 확인했다. `.runs/n10/protected-after.json`의 Expected 기준 보호 파일 **18/18 SHA-256 동일**을 확인했다. 증거는 `.runs/r44/protected-after.json`이다. 기준 manifest 자체의 정당성은 미검증이다. 시작 시 작업 트리는 깨끗했다.

대표/NightCoder 실행 명령:

```powershell
python -m pytest -q
python scripts/groundedness_eval.py --grader rule
python scripts/groundedness_eval.py --grader fake
```

## 설계 대비 차이

그래프 없는 단독 평가 범위이므로 체크포인터/thread, interrupt 승인, 관련성 재작성 루프, 이벤트 업로드를 연결하지 않았다(후속 연결 필요). 기존 `verify_report`의 명시적 인용·stance 계약을 사용하며 별도 조문/인과 의미 검사기를 임의로 추가하지 않았다. 없는 조문은 기존 수치·claim 대조가 탐지할 수 있으나 조문 전용 검사 성능으로 해석하면 안 된다. 인과 단정은 기존 규칙의 의미 해석 한계로 누락될 수 있으며 평가 결과에 그대로 드러나게 했다.

모든 문항은 compare 평가로 기록한다. 설정 선택·튜닝과 confirm 실행은 하지 않았다. 규칙과 fake 결과를 실제 모델 성능 표에 섞지 않는다. 토큰·비용·latency는 측정하지 않아 임의 추정 필드를 추가하지 않았다.

## 미검증

전체 시험, CLI 실행, 실제 탐지율·과차단률·오류 유형별 수치는 이 환경에서 미검증이다. 실제 모델·실제 문서 품질도 미검증이다. 모델·네트워크·다운로드·패키지 설치·키 조회는 수행하지 않았다. 실제 모델 실행용 CLI는 이번 범위에 없으며 `--grader llm` 같은 실행 명령을 제시하지 않는다. 향후 대표의 실제 모델 실행에는 호출자가 구성한 모델/마스커로 R42 StructuredLLMGrader를 만들고 `evaluate(cases, grader)`에 주입하는 후속 연결이 필요하다.

금지 파일·README·data·profiles·기존 시험을 변경하지 않았고, KNOWN_DEBT와 소스 모듈 경계를 변경하지 않았다. 현재 브랜치에서 작업했으며 push·원격/브랜치 설정 변경은 하지 않았다.

커밋 차단: 지정 네 파일의 `git add -- ...`가 `Unable to create .../.git/index.lock: Permission denied`로 실패했다. 이 환경의 `.git`은 읽기 전용이고 승인 정책이 never여서 권한 승격을 요청할 수 없다. 커밋 생성과 깨끗한 작업 트리 요구는 이 제약으로 이행하지 못했다. 구현을 삭제하지 않고 네 신규 파일을 남긴다. 커밋 해시는 없음. 쓰기 권한이 있는 NightCoder 환경에서 지정 네 파일을 stage/commit해야 한다.
