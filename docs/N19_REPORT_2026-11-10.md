# N19 보고서 — 어휘 처리 경계 시험

2026-11-10 KST. AGENTS.md를 먼저 읽고 현재 저장소·브랜치 `nc/rra-codex`에서 NightCoder 규칙을 적용했다.

## 구현

`tests/test_lexical_edges.py`에 매개변수 전개 기준 19건을 추가했다. 실제 `core.lexical.lex_terms`를 직접 호출하며 대체 구현·mock·fake 임베더·저장소가 필요하지 않다. 빈 문자열, ASCII/유니코드 공백, 한글·영문·숫자 혼합, 한 글자 제외, 전각 문자, 이모지, 구두점·마스크·연산자 제거, 중복과 순서, 대소문자, 10만 글자 단어를 검사한다. 같은 입력을 30번 호출한 값·순서의 결정성과 반환 리스트 수정 후 다음 호출의 독립성도 검사한다.

생산 코드·기존 시험·기대값·skip·KNOWN_DEBT는 수정하지 않았다. 신규 생산 모듈은 없다. Chroma 개발 기본값을 유지하고 memvid 의존성을 추가하지 않았다. 네트워크·모델 다운로드·실제 모델·LLM·LangSmith·패키지 설치·push·원격/브랜치 설정 변경은 수행하지 않았다.

## 관찰된 동작

다음은 소스 정적 확인에 근거한 현재 동작이며 런타임 관찰은 미검증이다. 기대값을 이 동작에 맞춰 명시적으로 고정했다.

- 전각 소문자·숫자는 전각 그대로 남고 반각 입력과 별개로 취급된다. 전각 대문자도 `isupper()` 필터로 제외된다. 폭 정규화는 없다.
- 이모지는 공백 구분자가 아니다. `ab😀cd`는 `abcd`, `한😀글`은 `한글`이 된다.
- 영문 소문자화는 하지 않는다. `English`와 `english`는 별개이고 `ENGLISH`는 제외된다.
- ASCII 연산자는 대소문자와 무관하게 제외하지만 전각 `ｏｒ`는 남는다.
- 공백으로 분리한 뒤 구두점을 제거하고, 중복은 최초 등장 순서로 제거한다. 단어 길이 상한은 없다.

## 시험 / 확인

파일 작성 후 전체 시험 명령을 시도했다.

```powershell
python -m pytest -q -p no:cacheprovider --basetemp=.runs/n19/full-tmp --junitxml=.runs/n19/full-pytest.xml
```

**tests not run here: Python is not available on PATH.**

이 환경에서 시험 미실행: `CommandNotFoundException`으로 명령을 시작하지 못했다. `python`, `py`를 찾지 못했고 저장소 `.venv-python`, `.venv-cache`에도 Python 실행 파일이 없었다. 실행 0건이며 passed/failed/error/skipped는 모두 집계 불가(미실행)다. 신규 19건은 작성 건수이며 통과 수치가 아니다. JUnit은 생성되지 않았다. 최종 시험 판정은 NightCoder 게이트가 필요하다.

보호 기준은 기존 `.runs/n10/protected-after.json`의 Expected SHA-256이다. 보호 파일 18/18은 기준·작업 전·후 모두 동일하다. 증거는 `.runs/n19/protected-before.json`, `.runs/n19/protected-after.json`에 저장했다. 초기 git status는 깨끗했고 지정 신규 두 파일만 추가했다. `git diff --check`는 통과했다.

## 입증하지 못한 것 / 미검증

Python 부재로 신규 시험과 전체 시험의 실행 결과, 매우 긴 단어의 런타임 처리와 반복 호출 결정성은 미검증이다. 검색 품질·실제 임베더·모델 평가는 수행하지 않았다. 이 작업은 순수 어휘 함수의 경계 시험이며 품질 비율이나 보장을 제시하지 않는다.
