## 무엇을 고쳤나

이번 체크아웃에서는 요청의 전제인 strict xfail 시험과 N21~N63 보고서가 확인되지 않아 생산 코드 결함 수정은 진행하지 않았다. N19·N20 보고서 전체와 연결된 `tests/test_lexical_edges.py`, `tests/test_sentences_edges.py`, 실제 `core/lexical.py`, `ingest/sentences.py`를 읽었다. 관찰된 동작을 결함으로 임의 재분류하거나 기존 기대값을 바꾸지 않았다. 이 보고서만 추가했다.

수정한 결함이 없으므로 새 회귀 시험도 추가하지 않았다. 기존 시험 44건(N19 19건, N20 25건)은 작성 건수이며 이번 실행 통과 수가 아니다. `KNOWN_DEBT`, 기존 시험, 동결 파일, memvid 코드는 변경하지 않았다. Chroma 기본값을 유지했으며 새 저장소 기능이나 대체 구현을 만들지 않았다.

## 시험

전체 시험 명령을 시도했다.

```powershell
python -m pytest -q -p no:cacheprovider --basetemp=.runs/r1/full-tmp --junitxml=.runs/r1/full-pytest.xml
```

**tests not run here: Python is not available on PATH.**

이 환경에서 시험 미실행: `CommandNotFoundException`으로 Python 명령을 시작하지 못했다. `python`, `py`, `pytest`가 PATH에 없고 `.venv-python`, `.venv-cache` 아래에서도 `python.exe`가 발견되지 않았다. 실행 0건. 최종 passed/failed/error/skipped는 모두 집계 불가(미실행)이며 JUnit은 생성되지 않았다. 시험 판정은 NightCoder 게이트가 필요하다.

보호 파일 18개는 `.runs/n10/protected-after.json`의 Expected SHA-256과 모두 동일하다. 작업 전·후 증거는 `.runs/r1/protected-before.json`, `.runs/r1/protected-after.json`에 저장한다. 결과 파일은 `.runs/`에만 두며 `git diff --check`로 공백 오류를 확인한다.

## 고치지 않은 것과 이유 / 미검증

- N21~N63의 실제 결함, strict xfail, 동결 masking 결함은 자료 부재로 미검증이다. 해당 보고서와 시험을 현재 브랜치에 연결한 뒤 재현·수정·회귀 검증이 필요하다.
- N19의 정규화·토큰 구분·길이 제한, N20의 문장 분리 정책은 설계 판단 없이 바꾸지 않았다. 현재 동작을 유지하거나 명시적으로 정책을 승인하는 선택지가 있다.
- 전체 시험 및 런타임 동작은 Python 부재로 미검증이다. 실제 모델·검색 품질 평가는 이 작업 범위가 아니며 실행하지 않았다.
- 네트워크, 모델 다운로드, LLM/유료 API, 패키지 설치, push, 원격·브랜치 설정 변경은 수행하지 않았다.
