# R43 종료 유형 연결 보고서

## 구현

- `ResearchResult.end_type`을 추가했다. 검수 통과는 `END`, 미통과·반복 한도 소진·진전 없음은 `give_up`, 노드 토큰·비용 제한은 `cutoff`다. 기존 `stopped` 값과 라우팅 설정은 유지한다.
- 결과에 실행 설정의 shadow 토큰 한도를 보관하여 이벤트 설정 없이도 예산 소진을 판별한다. `dataclasses.replace`로 결과를 변경할 때도 종료 유형을 다시 계산한다.
- 빈 초안으로 검수를 통과하지 못한 경우에도 미통과 사유를 안전 안내로 반환한다. 기존 부분 보고서에는 미통과 항목을 계속 붙인다.
- `event_from_result`는 결과의 종료 유형을 사용하고 기존 경로 기반 loops 계산을 유지한다.
- `EndType`에 `human`을 예약했다. 이번 요청의 “여기서는 값만 정의”에 따라 새 사람 승인 라우팅은 추가하지 않았다.
- 변경 파일은 허용된 네 파일뿐이다. 신규 패키지·모델·네트워크 호출·memvid 연결은 추가하지 않았다.

## 시험

신규 `tests/test_end_types.py`: 7개 함수, 매개변수 확장 시 8개 경로 시험. 실제 `ResearchRunner`, LangGraph 그래프, `MemorySaver`, 이벤트 어댑터를 사용한다. 검수 통과, 갭 한도 소진, 재작성 한도 소진과 빈 초안 안전 안내, 노드 토큰 제한, shadow 예산 소진, 예산 메타데이터 없는 이벤트 변환, 사람 검토 예약값·기존 중단/재개, 반복 한도 분류를 다룬다. 각 경로에서 결과와 이벤트의 종료 유형 및 loops를 대조한다. 모델 호출 없이 규칙 경로를 사용하는 경로 시험이며 실제 모델 품질 평가가 아니다.

실행 시도:

```powershell
.venv/Scripts/python.exe -m pytest -q -p no:cacheprovider -m "not memvid"
```

**tests not run here: the repository Python environment has no pytest module (No module named pytest).**

이 환경에서 시험 미실행: 저장소 Python에 pytest가 없다. langgraph와 langchain_core도 설치되어 있지 않다. 패키지 설치는 하지 않았다. 전체 시험의 최종 집계는 passed=0 / failed=0 / error=0 / skipped=0이며, 이는 시험 실행 전 명령 시작 실패에 따른 미집계다. pytest 종료 코드는 1이고 수집·실행된 시험은 0개다. 기존 memvid 시험은 수정·재시험·skip 처리하지 않았다. NightCoder 게이트 판정 필요.

별도 정적 확인: 변경 Python 파일 3개 AST 구문 검사 통과, `git diff --check` 통과. 위 결과는 pytest 통과 수에 포함하지 않는다.

보호 파일은 `.runs/n10/protected-after.json`의 Expected SHA-256과 현재 파일을 대조하여 **18/18 동일**이다. 증거: `.runs/r43/protected-after.json`. 기준 manifest 자체의 생성 정당성은 미검증이다. 기존 시험 파일과 금지 파일은 수정하지 않았다.

## 설계 대비 차이 / 후속 연결 필요

- `core/run_events.py`는 `human`을 허용하지 않는다. 이 파일은 이번 수정 허용 범위 밖이므로 변경하지 않았다. `human`은 타입 값만 예약했으며 실제 사람 검토 이벤트 발행은 R46에서 core 이벤트 스키마 확장 후 연결해야 한다. 현재 계획 검토 interrupt는 기존 시험과 호환되도록 `give_up`을 유지한다. 따라서 네 번째 유형의 실제 이벤트 경로는 이번 범위에서 구현·재현하지 않았다.
- 이벤트 메타데이터에 `max_shadow_tokens`를 명시하여 미통과 결과를 `cutoff`로 재분류하는 기존 동작은 기존 시험 불변 조건 때문에 유지했다. 이 명시적 호환 경로에서는 결과와 이벤트의 종료 유형이 다를 수 있다. 일반 호출에서는 결과 값을 그대로 전달한다.
- 기본 그래프·반복 상한·모델 옵션은 변경하지 않았다. 새 체크포인터·LLM 평가·사람 승인 기능을 추가하는 작업은 이번 종료 유형 연결 범위에 포함하지 않았다.

- 실제 모델 실행·LLM-as-judge·검색 품질·유료 비용은 미검증이다. 본 변경에는 실제 모델 실행 명령이 필요하지 않으며, 대표는 설치된 기존 환경에서 위 오프라인 시험 명령으로 먼저 검증할 수 있다.
- 커밋 미완료: 현재 브랜치 `nc/rra-codex`에서 지정된 네 파일의 `git add`와 `git commit`을 시도했으나 두 명령 모두 `.git/index.lock: Permission denied`로 실패했다. 이 샌드박스는 `.git` 읽기만 허용하고 승인 정책은 never이므로 권한을 확장할 수 없다. 새 커밋 해시는 없고 네 파일은 미커밋 상태로 보존했다. 기존 HEAD `20a8744`는 이번 작업의 커밋이 아니다. NightCoder의 스테이징·커밋 후속 조치가 필요하다. push·원격 설정·브랜치 설정 변경은 하지 않았다.
