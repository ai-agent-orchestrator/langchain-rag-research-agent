# R23 — 의료 도메인 필터 뼈대

## 구현

지정된 세 파일만 추가했다.

- `src/rag_research_agent/guard/medical_filter.py`
- `tests/test_medical_filter.py`
- `docs/R23_REPORT_2026-11-11.md`

`MedicalFilter`는 실제 DomainFilter의 InputDecision·Issue·Verdict를 사용하는 순수 Python
규칙 필터다. MATURITY는 incubating, 버전은 medical-filter/1이다. 합성·교육용이며 진단 도구가 아니다.
모듈 import 시 `register("medical", MedicalFilter)`와 공유 BUILTINS 항목을 등록한다.
명시적으로 선택하는 옵션이고 기본 그래프·기본 설정을 변경하지 않았다.

입력의 흉통·호흡곤란·의식 저하/소실·가슴 통증·심정지·심한 출혈을 EMERGENCY로 차단한다.
공백은 EMPTY_INPUT으로 차단한다. 응급 안내는 finalize와 별도의 고정 상수
EMERGENCY_ANSWER에 즉시 119 연락·응급실 안내로 정의했다.

검증은 단정 진단을 DEFINITIVE_DIAGNOSIS(재시도 불가), 근거의 명시적 금기 약물이
답변의 금기 표현에서 누락되면 CONTRAINDICATION_DROPPED, 근거에 없는 수치·단위 쌍을
UNSUPPORTED_DOSE로 반환한다. 후자의 두 문제는 재작성 가능하다. 중복 항목은 한 번 센다.
단정 진단은 근거가 없어도 코드를 유지하며 NO_EVIDENCE와 함께 안전 종료한다.
빈 답변은 EMPTY_ANSWER로 재작성 가능하다. 판정에는 코드·개수만 담는다.
finalize는 의료 자문 아님·전문의 상담 권고를 추가한다.

## 시험

합성 문장만 사용했다. 예약 가짜 개인정보조차 필요한 사례가 없어서 개인정보 모양의 값을 넣지 않았다.
research·legal·medical의 공통 등록 계약, 응급 키워드·공백, 단정 진단, 금기 누락·반전·중복·절/문서 격리,
용량 수치·단위·공백·대소문자·소수 표기·마이크로그램 표기, 인용 번호 제외, 다중 오류·고지를 검사한다.
실제 GuardrailRunner에서 응급 screen의 RAG 생략, 정상 답변 고지, 단정 진단의 재시도 중단,
용량 수정 후 통과, domain 미설정 기본 동작을 검사한다.
합성 답변을 반환하는 RAG 함수를 기존 주입 인터페이스로 전달하며 대체 그래프·필터·모델은 만들지 않았다.

전체 시험을 다음 명령으로 시도했다.

```powershell
python -m pytest -q -p no:cacheprovider --basetemp=.runs/r23/full-tmp --junitxml=.runs/r23/full-pytest.xml
```

**tests not run here: Python is not available on PATH.**

이 환경에서 시험 미실행: python 명령을 찾지 못해 전체 시험 명령이 시작되지 않았다.
python·py·pytest가 PATH에 없으며 저장소 .venv-python·.venv-cache 안에도 python.exe가 없었다.
실행 0건, passed/failed/error/skipped는 미실행으로 집계 불가다. 신규 시험도 통과로 주장하지 않는다.
기록은 `.runs/r23/test-attempt.txt`이며 JUnit 파일은 생성되지 않았다. NightCoder 게이트 판정이 필요하다.

## 설계 대비 차이·후속 연결 필요

중앙 domain_filter.py와 rag/guardrail_graph.py는 files 범위 밖이므로 수정하지 않았다.
의료 모듈을 명시적으로 import한 뒤 get_filter("medical")로 선택해야 한다.
최초 호출의 자동 import를 위한 중앙 BUILTINS 정적 항목 추가는 **후속 연결 필요**다.

현재 InputDecision에는 답변 필드가 없으며 기존 screen은 차단 시 일반 BLOCKED_ANSWER를 반환하고
finalize를 호출하지 않는다. 따라서 실제 그래프에서 EMERGENCY_ANSWER를 반환하도록 하는
screen의 코드별 고정 답변 매핑은 **후속 연결 필요**다. 이번 변경만으로 응급 안내가 사용자에게
전달된다고 주장하지 않는다. 응급 안내 상수를 finalize에 넣어 연결된 것처럼 만들지 않았다.
기본 classify가 짧은 입력을 smalltalk로 종료할 수 있어 screen 경로 시험에는 기존 router 옵션으로
research 라우팅을 주입했다. 기본 라우터를 통한 모든 응급 입력의 우선 screening도 **후속 연결 필요**다.

RESEARCH_GRAPH_DESIGN의 임상 가이드라인 근거 매핑·금기 약물 State·검색 경로 연결은
이번 뼈대에 포함하지 않았다. 새 import는 표준 라이브러리와 guard 내부 계약뿐이며
KNOWN_DEBT·LangChain/LangGraph 경계를 변경하지 않았다. Chroma/memvid 저장소를 사용하거나 변경하지 않았다.

## 미검증·한계·보호 확인

신규·전체 시험 실행, 임상 정확도·오탐률·미탐률, 실제 문서/모델 및 Chroma 종단 동작은 미검증이다.
규칙 필터라 모델 실행 명령은 해당하지 않는다. 모델·LLM 호출·다운로드·설치·네트워크 접근은 수행하지 않았다.

응급·진단은 어휘 검사이므로 부정·인용·과거 상황·교육 질문에서도 차단될 수 있다.
금기는 `약물A는 금기`, `금기: 약물A`, `금기 약물: 약물A` 등의 단일 토큰 약물명과 명시적 표현만
인식한다. `금기가 아님/아니다`의 단순 부정은 제외하지만 복합 부정·동의어·다중 약물 목록·조건의
의미를 검증하지 않는다. 조사 제거로 약물명 자체의 끝 글자를 오인할 수 있다.
용량은 mg·g·mcg/μg/µg·mL·정·캡슐의 수치/단위 쌍을 대조한다.
약물·환자·적응증과 용량의 대응, 빈도·체중당 용량·범위 하한·단위 환산은 검증하지 않는다.
동일 수치가 다른 약물에 붙어도 통과할 수 있다. 임상적 안전성을 입증하지 않았다.

보호 파일 18개는 `.runs/n10/protected-after.json`의 Expected를 기준으로 작업 전후
SHA-256 **18/18 동일**하다. 기록은 `.runs/r23/protected-before.json`과
`.runs/r23/protected-after.json`이다. 기준 manifest 생성 정당성은 미검증이다.
금지 파일·기존 시험·README를 변경하지 않았다. 결과 파일은 `.runs/r23/` 안에만 기록했다.
push·원격·브랜치 설정 변경은 하지 않았다.
