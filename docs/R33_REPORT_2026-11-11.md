# R33 리서치 실험 러너 문항 파일 선택

작업일: 2026-11-12 KST. NightCoder 레인에서 현재 저장소·브랜치로 작업했다.

## 구현

- `scripts/research_eval.py`: `--cases <파일>` 추가. 생략 시 기존 `evals/research/cases.ko.json`을 사용한다. 상대 경로는 현재 작업 디렉터리 기준이다.
- 기존 JSONL 필드와 설정·split·sweep 기본값을 유지하고 실행 기록에 `cases_file`(파일명), `cases_sha256`(파일 원본 바이트의 SHA-256)을 추가했다. 파싱과 해시는 같은 바이트를 사용한다.
- 없는 파일 등 읽기 실패는 argparse 오류 메시지와 종료 코드 2로 처리하며 결과 파일을 만들지 않는다.
- `tests/test_research_eval_cases_option.py`: 옵션 생략, 기존 파일 명시, R24 v2 상대 경로, 없는 파일 오류의 4개 시험. 실제 ResearchRunner·baseline·보드 렌더러를 사용하고 파일명·해시·기존 기록 필드·compare 문항 ID·설정 목록을 확인한다. 대역 클래스나 모델 호출은 없다. 시험 산출물은 `.runs/r33/` 내부 임시 디렉터리에 작성하고 정리한다.

## 시험

전체 시험 시도 명령(NightCoder의 memvid 표식 제외 범위):

```powershell
.\.venv\Scripts\python.exe -m pytest -q -m 'not memvid' --basetemp=.runs/r33/pytest-tmp
```

**tests not run here: repository virtualenv Python has no pytest module.**
이 환경에서 시험 미실행: `No module named pytest`로 수집 전에 종료했다. PATH의 python도 없다. 전체 시험 passed/failed/error/skipped는 집계 불가이며 실행 사례는 0개다. 로그: `.runs/r33/full-tests.txt`.

추가 실행 시도:

```powershell
.\.venv\Scripts\python.exe -m unittest tests.test_research_eval_cases_option -v
```

실제 러너 import 시 `No module named 'langgraph'`로 로드 실패했다. unittest 출력은 `Ran 1 test`, `FAILED (errors=1)`이며 이는 로더 오류 1개다. 신규 기능 시험 4개는 실행되지 않았다. passed=0, failed=0, error=1, skipped=0(로더 오류만 집계). 로그: `.runs/r33/target-tests.txt`. 패키지 설치나 대역 주입으로 우회하지 않았다.

두 Python 파일의 표준 라이브러리 AST 구문 검사와 `git diff --check`는 통과했다. 기능 동작 판정은 NightCoder 게이트에서 필요하다.

대표 재실행 명령:

```powershell
.\.venv\Scripts\python.exe -m pytest -q tests/test_research_eval_cases_option.py --basetemp=.runs/r33/target-tmp
.\.venv\Scripts\python.exe scripts/research_eval.py --cases evals/research/cases_v2.ko.json --split compare
```

두 번째 명령은 기존 규칙 기반 경로 실행용이다. 실제 모델 실행 인터페이스 추가는 이 작업 범위에 없으므로 실제 모델 실행 명령은 해당하지 않는다. 설정 선택이나 confirm 실행은 하지 않았다.

설계 정본의 그래프·도메인 필터·가드레일 계약 변경은 없다. 문항 파일 선택과 실행 출처 기록만 스크립트 경계에 추가했다. 새 모듈 간 import, KNOWN_DEBT 증가, 저장소 구현 변경은 없다. Chroma/memvid를 새로 요구하지 않는다.

## 미검증 및 보호 파일

의존성 부재로 신규 기능과 전체 회귀 시험은 미검증이다. 네트워크·모델 다운로드·LLM 호출·새 패키지 설치는 하지 않았다. 개인정보 모양의 시험 데이터도 추가하지 않았다.
