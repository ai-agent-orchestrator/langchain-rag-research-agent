# R49 판정기 슬롯

## 구현

- `rag/judge.py`: `JudgeVerdict`는 Pydantic 구조화 모델로 정수 score 1~5, bool correct, str reason을 엄격히 검증한다. 범위 밖·문자열 점수·bool 점수·추가 필드를 거절하며 불변이다. `Judge.judge(question, answer, reference)` 프로토콜로 모델 공급자와 평가기를 분리했다. MATURITY는 incubating이다.
- `FakeJudge`는 참고 답안의 Unicode 단어를 대소문자 정규화·중복 제거하고 답변에 포함된 핵심어 수를 센다. 점수는 `1 + floor(4 * 포함 수 / 핵심어 수)`, correct는 score >= 4다. 핵심어가 없는 참고 답안은 오류다. 질문 의미·동의어·부정문을 판단하지 않는 **경로 시험**이다.
- `StructuredLLMJudge`는 호출자가 주입한 모델의 `with_structured_output(JudgeVerdict)`를 호출한다. 기존 structured grader와 같이 마스커가 필수이고 질문·답변·참고 답안을 모두 마스킹한다. JSON DATA 경계의 꺾쇠를 이스케이프하고 입력은 지시가 아닌 데이터임을 명시한다. 기존 `serving_trace_guard`와 `serving_config`를 재사용하며 출력 검증·모델 오류는 전파한다. 공급자·클라이언트·모델을 생성하지 않는다.
- `scripts/domain_eval.py --judge none|fake`: 기본 none은 기존 출력 필드·채점을 유지한다. fake일 때만 judge 집계와 문항별 구조화 판정, 별도 `judge_disagreements` 목록을 추가하고 `fake_rule_path_test`로 표시한다. `evaluate(..., judge=...)`에는 프로토콜 구현을 주입할 수 있다.
- reference가 있는 선택 split 문항만 판정한다. injection은 판정 품질 분모에서도 제외한다. 누락 reference는 건너뛰며 명시된 빈 값·잘못된 타입은 오류다. 출력은 `answer`, 없으면 리서치 어댑터의 `body`를 사용한다. 질문·답변은 문자열이어야 한다.
- 집계는 문항 수 n, 평균 점수 mean_score, 정답 수 ok/표본 수 n/정답률 rate/Wilson 95% 구간이다. 판정 표본이 없으면 평균·비율·구간은 null이다. 0건은 보장을 뜻하지 않는다. 기존 규칙 품질·안전 지표 및 검색 지표와 섞지 않는다.
- 엇갈림은 각 문항의 judge.correct와 각 규칙 지표의 전체 체크 통과 여부를 비교한다. 품질·안전 지표 모두 대상이며 체크가 0개인 지표는 비교하지 않는다. 문항 ID·판정 정답 여부·엇갈린 규칙 지표와 통과 여부만 별도 목록에 남긴다. 원문 복사는 추가하지 않았다. 목록은 기존 `.runs/domain_eval/<domain>/runs.jsonl` 결과에 저장된다.

## 설계 대비 차이와 후속 연결 필요

이번 범위는 오프라인 참고 답안 평가 경계다. `METRICS_BOARD.ko.md`의 실행 이벤트·end_type 및 그래프의 관련성/근거성 채점·재작성·포기·체크포인터·thread·interrupt 계약은 변경하지 않는다. 평가 판정을 실행 그래프의 검수 판정으로 대체하지 않는다. 이벤트 보드에 판정 집계를 연결하는 작업은 허용 파일 범위 밖이므로 **후속 연결 필요**다.

구조화 모델 래퍼의 필수 마스커와 tracing 차단은 기존 구조화 채점기·가드레일 설계의 보안 순서를 따른다. CLI에는 요청된 none/fake만 제공한다. 실제 모델 CLI·공급자 선택·모델 다운로드 기능을 임의로 추가하지 않았다. Chroma 기본 및 모듈 경계를 유지하고 새 memvid 의존성을 추가하지 않았다. KNOWN_DEBT 증가와 기존 시험 변경은 없다.

## 미검증 및 실행 안내

실제 LLM 판정 정확도·일관성·프롬프트 주입 내성·토큰 비용, 실제 임베딩/Chroma 검색 품질은 미검증이다. 실제 모델 실행·다운로드·네트워크·LangSmith 업로드·유료 API·패키지 설치는 수행하지 않았다. 구조화 출력만으로 의미적 정답성을 보장하지 않는다.

대표의 실제 모델 실행 진입점은 `StructuredLLMJudge(model, masker)`를 `evaluate(..., judge=...)`에 주입하는 Python API다. 현재 CLI에는 실제 모델 실행 옵션이 없으므로 실행 가능한 실제 모델 CLI 명령은 제공할 수 없다. 공급자 주입 명령 연결은 **후속 연결 필요**다. 현재 지원하는 오프라인 경로 명령은 다음과 같다. 기존 research 문항에 reference가 없으면 판정 표본 수는 0이다.

```powershell
& .runs/r40-retry/venv/Scripts/python.exe scripts/domain_eval.py --domain research --judge fake
```
