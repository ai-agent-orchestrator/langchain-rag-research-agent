# R35 — 실행 이벤트 스키마와 원가 환산

## 구현

누락되어 있던 `docs/METRICS_BOARD.ko.md`를 지시문의 정본 내용 그대로 추가했다.
`core/run_events.py`는 MATURITY=incubating인 독립 계약 모듈이다.
불변 데이터클래스 RunEvent·NodeEvent, 메서드 및 모듈 함수 to_json/from_json,
모델별 토큰 수를 원으로 환산하는 cost_krw를 제공한다. 기본 실행 경로는 변경하지 않았다.

중첩 객체는 입력을 복사한 불변 Mapping, 배열은 tuple로 저장하며 JSON에서는
정본의 객체·배열과 필드 이름으로 복원한다. 모든 필수 필드와 중첩 필드를 검사하고,
알 수 없는 필드·음수·비유한 수·정수가 아닌 카운터·잘못된 track/end_type을 거부한다.
grade의 문서 수와 비율 범위를 검사한다. 탈락률 자체의 재계산이나 검색 품질 평가는 하지 않는다.
guard의 reason/span은 호출자가 이미 마스킹한 문자열을 전달해야 한다. 자동 수집·마스킹은 없다.

model=None인 규칙 노드는 estimated=true로 정규화한다. 추정 노드가 포함된 run도
estimated=true가 된다. 모델 노드에서도 추정 토큰이면 명시적으로 true를 전달할 수 있다.
`evals/pricing.json`의 fake-slm·fake-flagship은 임의 단가이며 실제 모델 가격이 아니다.
단위는 입력·출력 각각 **백만 토큰당 원**이다. 사용한 모델의 단가가 없으면 KeyError로
실패하고 무료로 간주하지 않는다. 계산 결과는 반올림하지 않은 float다.

사용 예시(모델 호출·파일 쓰기 없음):

```python
import json
from rag_research_agent.core.run_events import RunEvent, cost_krw

# event는 호출부가 구성한 RunEvent
encoded = event.to_json(dumps=json.dumps)
restored = RunEvent.from_json(encoded, loads=json.loads)
amount = cost_krw(
    {"fake-slm": {"in": 120, "out": 20}},
    {"fake-slm": {"in": 100.0, "out": 200.0}},
)  # 0.016원 (임의 단가)
```

## 시험

신규 `tests/test_run_events.py`는 실제 RunEvent·NodeEvent와 표준 json 코덱을 사용한다.
왕복 직렬화, 모든 필수 필드 누락, 중첩 필드 누락, 잘못된 값·추가 필드,
규칙 노드 추정 표시, 중첩 불변성·입력 변경 격리, 실제 pricing.json을 읽은
모델별 입력·출력 원가 합산, 빈 사용량·미등록 모델·잘못된 단가를 검사한다.
대체 이벤트 구현·LLM·네트워크는 사용하지 않는다. 기존 시험·기대값·skip은 변경하지 않았다.

전체 시험 실행 시도 명령:

```powershell
python -m pytest -q -p no:cacheprovider --basetemp=.runs/r35/full-tmp --junitxml=.runs/r35/full-pytest.xml
```

**tests not run here: Python is not available on PATH.**

이 환경에서 시험 미실행: python 명령이 없어 시험 명령을 시작하지 못했다.
python·python3·py가 PATH에 없으며 .venv-python·.venv-cache에서도 python.exe를 찾지 못했다.
실행 0건. passed/failed/error/skipped는 미실행으로 집계 불가이며,
시험 통과를 주장하지 않는다. `.runs/r35/test-attempt.txt`에 이유를 기록했다.
NightCoder 게이트에서 신규 시험과 전체 시험 실행이 필요하다.

## 설계 대비 차이

tests/test_structure.py는 core import를 제한하며 표준 json도 허용하지 않는다.
이를 우회하거나 기존 시험을 바꾸지 않고, 호출부에서 dumps/loads 코덱을 주입하도록 했다.
따라서 인수 없는 to_json/from_json은 제공하지 않는다. JSON 필드 이름은 정본과 같다.
정본 예제 JSON에는 estimated가 생략되어 있으나 본문의 추정 표시 요건과 작업 지시에 따라
run과 node 모두 필수 estimated 필드를 둔다. domain은 향후 도메인 확장을 위해 문자열 계약이다.

cost_krw의 tokens는 모델명 → {in, out} 집계다. RunEvent.tokens의 전체 합계만으로는
서로 다른 모델 단가를 구분할 수 없으므로 호출부가 모델별 집계를 전달해야 한다.
단가 파일 로딩·노드별 토큰 집계·그래프 콜백·JSONL 저장·보드 연결은 **후속 연결 필요**다.
허용된 다섯 파일만 추가했다. 모듈 간 import나 KNOWN_DEBT 증가는 없다.

## 미검증·보호 확인

Python 실행에 따른 신규·전체 시험 결과, 실제 모델 토큰 및 원가, 수집 콜백과 보드의
종단 동작은 **미검증**이다. 본 작업에는 모델 실행이 필요하지 않아 실제 모델 실행 명령은
해당하지 않는다. 모델 호출·다운로드·설치·네트워크·원격 tracing은 수행하지 않았다.
새 memvid 의존성은 없다. 기존 Chroma 기본 경로는 변경하지 않았다.

보호 파일 SHA-256은 기존 `.runs/n10/protected-after.json`의 Expected를 기준으로
작업 전후 **18/18 동일**하다. 기준 manifest 생성 정당성은 미검증이다.
확인 결과는 `.runs/r35/protected-before.json`과 `.runs/r35/protected-after.json`에 기록했다.
결과 파일은 .runs/r35/에만 썼다. 금지 파일·기존 시험·README는 변경하지 않았다.
