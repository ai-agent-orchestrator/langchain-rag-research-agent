## 구현

- 신규 `tests/test_retry_graph_edges.py`에 매개변수 전개 기준 13건을 추가했다. 생산 코드와 기존 시험은 변경하지 않았다.
- 기존 E2 시험과 같은 `SimpleNamespace` 청크·메모리 검색 Library 구성을 사용한다. 검색 응답과 호출 이력만 시험에서 제어하고 실제 `build_graph`, `rewrite_queries`, `ServingGraph`, Equalizer 단계와 실제 `RetrievalUnavailable` 예외를 사용한다. 그래프·재작성 함수를 대체하거나 monkeypatch하지 않는다.
- 원 질의와 동일한 변형만 있어 중복 제거 후 0개가 되는 경우 최초 검색 1회로 끝나는지 확인한다. 숫자·기간만 있는 질의, 숫자만 있는 질의, 접속어만 있는 질의, 29,999자 질의를 실제 재작성 함수와 그래프에 전달하고 변형 내용·순서, 검색 호출 수, 시도 수와 REQUEST_MORE를 검사한다.
- 원 질의 → 하위 질의 2개 묶음 → 기간 제거 질의로 총 3회 시도를 구성했다. 마지막 점수가 τ=0.5와 같으면 성공하고 0.49이면 REQUEST_MORE여야 한다. 시도 번호·질의·변형 사유·출처 청크 ID·누적 융합 검색 점수·순위·최고 점수·τ·충분성의 개수와 순서를 구체적인 기대값으로 검사한다. 성공 시 실제 Equalizer의 최종 프롬프트와 compose_and_check 실행도 확인한다.
- max_retries=0/1/2 각각의 총 시도 수 1/2/3과 개별 검색 호출 수 1/3/4를 검사한다. 두 번째 시도의 첫·두 번째 검색, 세 번째 시도의 검색에서 장애를 발생시켜 같은 예외 객체가 호출자에게 전달되고 후속 검색이 중단되는지 검사한다.
- 모두 오프라인 **경로 시험**이다. 네트워크·모델 다운로드·실제 모델·LLM 호출·패키지 설치·memvid 의존성을 추가하지 않았다. 새 생산 모듈과 KNOWN_DEBT 변경이 없다.

```powershell
python -m pytest -q -p no:cacheprovider --basetemp=.runs/n15/full-tmp --junitxml=.runs/n15/full-pytest.xml
```

이 환경에서 시험 미실행: 위 명령이 `CommandNotFoundException`으로 시작되지 않았다. `Get-Command python,py,pytest`에서도 실행 명령을 찾지 못했다. 실행 0건이며 passed/failed/error/skipped는 모두 집계 불가(미실행)다. 신규 13건은 작성 건수이며 통과 수치가 아니다. pytest가 시작되지 않아 JUnit 결과도 생성되지 않았다. 최종 판정은 NightCoder 게이트에서 필요하다.

보호 기준은 기존 `.runs/n10/protected-after.json`의 Expected SHA-256이다. 보호 파일 18개는 기준·작업 전·후 모두 동일하다. 증거는 `.runs/n15/protected-before.json`, `.runs/n15/protected-after.json`에 보관했다. 초기 git status는 깨끗했다. 지정 신규 시험·보고서 외에 기존 시험·금지 소스·data·profiles·frozen masking·README를 변경하지 않았다. `git diff --check`를 확인했다.

## 입증하지 못한 것 / 미검증

- Python 부재로 신규 시험과 전체 시험의 실행 결과 및 통과 여부는 **미검증**이다. 기대와 다른 런타임 동작은 관찰하지 못했으며 기대값을 실행 결과에 맞춰 변경하지 않았다.
- 실제 기록에는 출처 문서 ID 필드가 별도로 없고 `hits[].chunk_id`가 있다. 이번 시험은 해당 청크 ID와 점수·순위 순서를 검사한다. 문서 ID의 별도 기록이 필요하다면 후속 연결 필요다.
- 실제 임베더·Chroma 검색 품질·외부 검색 장애의 발생 조건은 미검증이다. 실제 모델 실행은 이번 작업 범위에서 금지되어 실행 명령도 추가하지 않았다.
