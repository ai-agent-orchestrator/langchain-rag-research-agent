# R7 보고서 — 보고서 나란히 비교

## 무엇을 고쳤나

- 기존 보드 영역을 보존하고 문항·왼쪽 설정·오른쪽 설정 선택기를 갖춘 보고서 비교 영역을 추가했다. 기본값은 baseline_single과 graph_full이다. 해당 설정이 없으면 사용 가능한 설정을 선택하고, 설정이 하나면 양쪽에 같은 설정을 표시한다. 선택 문항의 보고서가 없는 설정은 안내문을 표시한다. 작은 화면에서는 두 패널을 세로로 배치한다.
- 각 보고서 옆에 gold 지표·인과·조건·반대 근거 평가를 표시한다. 누락은 빨강, 반영은 초록, 평가 결과가 없으면 회색과 미검증 문구를 쓴다. 정답에 반대 근거가 없는 문항은 평가 제외로 표시한다. 반대 근거는 기존 scorer의 하나 이상 반영 여부를 그대로 사용하며 개별 반대 문장을 모두 평가했다고 주장하지 않는다.
- 기존 runs 기록에는 gold 원문이 없다. render()가 evals/research/cases.ko.json을 읽어 데이터셋 버전·문항 ID가 일치할 때만 gold와 질문을 사본에 연결한다. 입력 기록은 변경하지 않는다. 미연결 기록은 기존 점수의 항목명·번호만 표시한다. 저장소·임베더·모델 연결 변경은 없다.
- 보고서와 정답 문자열은 HTML escape한다. 기존 JSON의 종료 태그 escape를 유지하고 대소문자 혼합 `</ScRiPt>`도 회귀 시험에 포함했다.

## 시험

신규 tests/test_research_board.py에 회귀 시험 4개를 작성했다. 단일 문항·단일 설정 및 반대 근거 없음, 입력 불변성, 종료 script 태그 escape, 버전 일치 시에만 gold 연결, 실제 JavaScript 출력 함수의 누락 색·본문 escape·보고서 없음·반대 근거 누락을 확인한다. JavaScript 시험은 설치된 Node.js를 사용하며 대체 DOM이나 가짜 구현을 만들지 않는다.

전체 시험 명령:

```powershell
python -m pytest -q -p no:cacheprovider --basetemp=.runs/r7/full-tmp
```

tests not run here: Python executable is unavailable (CommandNotFoundException).
이 환경에서 시험 미실행: Python 실행기를 찾을 수 없어 명령을 시작하지 못했다. pytest 실행 0건이며 passed/failed/error/skipped 집계는 불가하다. 신규 Python 회귀 시험 4개도 실행 미검증이다. NightCoder 게이트에서 위 명령으로 확인해야 한다.

별도 실행 검증: 설치된 Node.js로 실제 TEMPLATE의 전체 JavaScript를 추출하여 `node --check .runs/r7/board.cjs` 구문 검사를 통과했다. 실제 reportPanel 함수에 대한 합성 데이터 검증 7개도 `node .runs/r7/formatter.cjs`로 통과했다. 이것은 출력 경로 시험이며 pytest 집계나 모델 품질 평가를 대체하지 않는다. 네트워크·모델·LLM 호출·설치는 수행하지 않았다.

## 고치지 않은 것과 이유 / 미검증

브라우저에서 선택기 조작과 시각 배치의 실제 동작은 미검증이다. 과거 데이터셋 버전의 gold 복원과 항목별 반대 근거 재채점은 하지 않았다. 기존 평가 의미를 유지하며 알 수 없는 결과는 미검증으로 표시한다. 실제 모델 실행은 이번 작업에서 금지되어 실행하지 않았으며 모델 실행 명령도 추가하지 않았다.

기존 시험·기대값·skip·KNOWN_DEBT, data/profiles, 동결 masking, memvid, tracing, README와 금지 파일은 변경하지 않았다. 지정된 scripts/research_board.py, 신규 tests/test_research_board.py, 본 보고서만 변경한다. 결과 파일은 .runs/r7/ 안에만 쓴다.

보호 파일 18개는 기존 .runs/n10/protected-after.json의 Expected와 SHA-256이 18/18 동일하다. 작업 전·후 증거는 .runs/r7/protected-before.json, .runs/r7/protected-after.json이다. `git diff --check`를 통과했다.

## 커밋 제약

초기 git status는 깨끗했다. 현재 브랜치에서 지정 파일의 git add를 시도했으나 `fatal: Unable to create 'C:/work/rra-codex/.git/index.lock': Permission denied`로 실패했다. 이 샌드박스의 .git은 읽기 전용이며 권한 상승은 허용되지 않는다. 커밋 명령의 결과도 아래 최종 확인에 기록한다. push·원격·브랜치 설정 변경은 하지 않았다.

최종 확인: 세 파일을 지정한 git add와 `git commit -m "feat: compare research reports alongside gold coverage (R7)"` 모두 같은 index.lock 권한 오류로 실패했다. 커밋 해시는 없다. 미커밋 변경 0건 조건은 충족하지 못했으며 구현·시험·보고서를 삭제하지 않고 보존한다. Git 쓰기가 가능한 NightCoder 환경에서 이 세 파일을 단일 커밋으로 수집해야 한다.
