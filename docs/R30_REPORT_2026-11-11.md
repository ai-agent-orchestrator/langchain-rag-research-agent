## 구현

`guard/local_admin_filter.py`에 `LocalAdminFilter`, `local-admin-filter/1`, `MATURITY = "incubating"`을 추가했다.
실제 DomainFilter의 InputDecision·Issue·Verdict를 사용한다. 가상 시·군·구 키워드와 신청 유형을 코드 branch로
분기하며 관할 누락·복수 관할·빈 입력을 차단한다. 개정·시행일이 명시된 양식/기준 버전,
지역 예외 내용, 필수 구비서류를 대조하고 통과한 답변에 담당 기관 확인 안내를 추가한다.

모듈 import 시 `register("local_admin", LocalAdminFilter)`와 공유 BUILTINS 갱신을 수행한다.
기존 GuardrailRunner의 domain 옵션으로만 선택한다. 기본 그래프·설정, 기존 시험·기대값·skip은 변경하지 않았다.
새 import는 표준 라이브러리와 guard 내부 계약뿐이며 KNOWN_DEBT를 늘리지 않았다.
Chroma 기본 경로를 유지하며 새 memvid 의존성, 네트워크·LLM·모델 호출, 설치·다운로드는 없다.

변경 파일은 지정된 다음 네 개다.

- `src/rag_research_agent/guard/local_admin_filter.py` (신규)
- `tests/test_local_admin_filter.py` (신규)
- `docs/DOMAIN_FILTERS.ko.md`
- `docs/R30_REPORT_2026-11-11.md` (신규)

## 시험

공통 계약을 research·legal·medical·local_admin에 적용하는 신규 시험을 정의했다.
관할·신청 유형·복수/누락 관할, 버전별 최신값과 날짜 정규화, 절·문서 간 개정 표식 격리,
예외·서류의 고유 항목 누락 개수와 목록 형식, 빈 근거·빈 답변, 코드만 반환하는 결과와 고지를 검사한다.
실제 GuardrailRunner·GuidanceReply·필터 클래스를 사용하여 통과·재시도·안전 종료·입력 차단·기본 경로 보존도 검사한다.
주입한 비동기 RAG 함수는 합성 답변·근거만 반환한다. 그래프나 필터의 대체 구현은 만들지 않았다.
실제 지자체 규정·연락처·개인정보 모양 데이터는 사용하지 않았다.

시험 명령과 최종 결과는 아래 실행 기록에 적는다. 결과 파일은 `.runs/r30/`에만 둔다.

## 설계 대비 차이

규칙 뼈대가 인식하는 명시적 근거 형식과 입력 분기 우선순위는 DOMAIN_FILTERS 문서에 기록했다.
최신값은 해당 근거 안의 양식/기준 종류·척도별 최대값이며 실제 유효일·현재 시각이나 법적 효력을 판정하지 않는다.
같은 절의 여러 버전/날짜는 서로 연결된 것으로 본다. 과거 양식의 정당한 설명·부정문을 해석하지 않는다.
예외·서류는 공백 정규화 후 전체 문자열 포함으로 비교하므로 동의어·조사·부분 문자열·부정문에서 오판할 수 있다.

중앙 domain_filter.py와 검색/그래프 파일은 files 범위 밖이라 수정하지 않았다.
명시적 모듈 import 전의 최초 get_filter 자동 로딩, 관할별 검색 격리·최신 규정 DB 강제,
State 서류 체크리스트 연결은 **후속 연결 필요**다. 서로 다른 관할·신청·서식의 근거 격리는 호출자 책임이다.
