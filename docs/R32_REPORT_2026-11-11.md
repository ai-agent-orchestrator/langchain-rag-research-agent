# R32 의료 합성 평가 팩

작업일: 2026-11-12 KST. NightCoder 레인, 현재 저장소·브랜치에서 작업했다.

## 구현

- `evals/domains/medical/cases.json`: 응급 2개, 금기 약물 3개, 일반 3개로 구성한 합성 교육 시나리오다. 실제 환자·실제 약물·용량 권고는 없다. 약물 이름은 약물A부터 약물E까지이며 개인정보 모양의 값은 사용하지 않았다. 모든 문항은 compare다. 선택이나 confirm 실행은 하지 않았다.
- `evals/domains/medical/metrics.json`: 응급 즉시 차단률과 안전 지표인 단정 진단 수·금기 누락 수·근거 없는 용량 수를 R21의 기존 선언형 계약으로 정의했다. 일반 문항의 `gold.emergency_checks`는 빈 목록이므로 응급 차단률의 분모는 응급 2개다. safety count는 판정 코드 목록의 길이이며, 위반 문항 수와 발생 개수는 구별한다.
- `tests/test_medical_eval_pack.py`: 형식·분포·근거·참조 출력 일관성, R21 로드/평가/기록, 응급 선차단, 응급 미차단 시 분모, 금기 누락·부정 반전, 중복 금기/용량 집계, 진단 단정·용량 오류 복합 판정, 개인정보 모양 부재를 검증하는 9개 시험 함수(매개변수 확장 21개 사례)다.
- 시험의 `verified_output`은 실제 `MedicalFilter.check_input/verify`를 호출한다. gold와 저장된 안전 목록을 판정에 사용하지 않고 `Issue.count`에서 목록을 다시 만든다. 응급은 output과 docs에 접근하기 전에 반환한다. 오류 용량은 가상 파서 오류 토큰이며 복용 권고가 아니다. 모델·임베더·저장소 대역은 만들지 않았다.

## 시험

전체 시험 시도 명령(NightCoder의 memvid 표식 제외 범위):

```powershell
.\.venv\Scripts\python.exe -m pytest -q -m 'not memvid' --basetemp=.runs/r32/pytest-tmp
```

**tests not run here: repository virtualenv Python has no pytest module.**
이 환경에서 시험 미실행: 저장소 가상환경 Python 3.15.2에서 `No module named pytest`로 수집 전에 종료했다. PATH에 python·py도 없으며 패키지는 설치하지 않았다. 전체 pytest의 passed/failed/error/skipped는 모두 집계 불가, 실행 사례는 0개다. 실행 판정은 NightCoder 게이트가 필요하다. 로그: `.runs/r32/full-tests.txt`.

별도 표준 라이브러리 직접 점검은 통과했다. 신규 시험의 pytest import와 매개변수 데코레이터를 제외한 AST를 실행하여 20개 assertion 점검 호출을 수행했고, 실제 R21 `run`의 JSONL 쓰기·읽기와 원문 비기록도 직접 확인했다. pytest 대역은 만들지 않았으며 pytest 수집·fixture 실행을 검증한 것은 아니다. 기록은 `.runs/r32/check.py`, `.runs/r32/direct-checks.txt`, `.runs/r32/domain_eval/medical/runs.jsonl`에 있다.

## 설계 대비 차이

설계 정본의 도메인 교체 경계에 따라 기존 순수 Python MedicalFilter와 범용 R21 러너를 재사용했다. 프로덕션 코드·기본 설정·KNOWN_DEBT를 변경하지 않았다. R21에는 지표별 문항 조건 필드가 없으므로 기존 contains 지표와 문항별 빈 기대 목록으로 응급 분모를 표현했다. 응급 지표의 safety=false는 R21에서 성공률을 표시하기 위한 계약이며, 나머지 세 가지 오류 개수는 safety=true로 분리한다.

실행형 의료 어댑터를 R21 CLI에 연결하는 작업은 지정 파일 범위 밖이므로 **후속 연결 필요**다. 이번 어댑터는 시험 안에서만 주입한다. R23의 응급 고정 안내를 그래프 BLOCKED 응답에 연결하는 것과 최초 의료 필터 자동 로딩도 **후속 연결 필요**이며 이 팩의 통과 결과로 그래프 전체 동작을 주장하지 않는다. 근거 문구는 기존 필터가 지원하는 명시적 금기 형식을 사용한다. 접두 설명이 금기 약물명으로 인식될 수 있는 규칙 파서의 한계는 수정하지 않았다.
