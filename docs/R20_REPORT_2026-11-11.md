# R20 — 리서치 노드 주입 계약

## 구현

`build_research_graph`에 선택적 keyword 인자 `planner`, `extractor`, `writer`,
`verifier`, `refiner`, `fallback_on_error=True`를 추가했다.
PlannerFn·ExtractorFn·WriterFn·RefinerFn은 Callable 타입이며 VerifierFn은
keyword-only `expect_balance`를 표현하는 Protocol이다.

계약은 기존 규칙 함수와 같다. planner는 질문·체크리스트·설정에서 ResearchPlan,
extractor는 출처·계획·기존 claim ID에서 claims/metrics/relations,
writer는 계획·claims·feedback·설정·반대 근거 부재 여부에서 Draft,
verifier는 Draft·계획·claims·metrics·expect_balance에서 판정 코드 tuple,
refiner는 출처·설정에서 정제 출처와 로그 코드 목록을 반환한다.
기존 refine 구현을 그대로 refine_rule 순수 함수로 옮겼다.

미주입 시 기존 규칙 및 기존 LLM 설정 경로를 유지한다. 명시적 planner/extractor는
해당 LLM 설정보다 우선하며 모델·masker 생성 없이 사용된다. 주입 함수의 Exception은
규칙 기본값으로 폴백하고 `PLUGIN_FALLBACK:PLANNER` 등 고정 코드만 기록한다.
예외 메시지는 기록하지 않는다. False이면 원래 예외를 전파한다.
규칙 함수 자체의 예외와 BaseException은 숨기지 않는다.
입출력은 이미 마스킹되었다는 기존 계약을 유지하며 주입 함수는 입력을 변경하지 않아야 한다.

추출 결과는 기존 span 검증을 계속 통과해야 한다. 리듀서·coverage·검수 후 라우팅·
비용 집계·체크포인트 변환을 기존 그래프에서 수행하며 대체 그래프를 만들지 않았다.
새 import는 표준 typing.Protocol뿐이고 MATURITY·KNOWN_DEBT는 유지한다.
memvid 의존성·저장소 경로·기본 설정값 변경은 없다.

## 시험

신규 시험은 매개변수 포함 22건의 오프라인 경로 시험이다. 다섯 노드별 결과 변경,
각 노드의 폴백 및 비활성화, 예외 문자열 미기록, 잘못된 span 제거,
기본·문단 정제·병렬 설정에서 명시적 규칙과 기본 State 동등성,
LLM 설정 대비 주입 우선순위, 실제 InMemorySaver 직렬화,
검수 플러그인에서 작성 feedback으로 이어지는 재작성 라우팅을 다룬다.
실제 컴파일된 StateGraph·core 데이터 클래스·규칙 함수·검색 함수를 사용하고
교체 함수만 시험용으로 주입한다. 네트워크·모델·다운로드를 사용하지 않는다.

전체 시험 시도 명령:

```powershell
python -m pytest -q -p no:cacheprovider --basetemp=.runs/r20/full-tmp --junitxml=.runs/r20/full-pytest.xml
```

**tests not run here: Python is not available on PATH.**

이 환경에서 시험 미실행: python 명령을 찾지 못했다. py·pytest도 PATH에 없으며
저장소 .venv-python·.venv-cache에 python.exe가 없다.
실행 0건. passed/failed/error/skipped는 시험 미시작으로 집계 불가다.
NightCoder 게이트에서 기존 research 시험과 전체 시험 판정이 필요하다.
시도 기록은 `.runs/r20/test-attempt.txt`다. 기존 시험·기대값·skip은 변경하지 않았다.

`git diff --check` 통과. 보호 파일은 기존 `.runs/n10/protected-after.json`의
Expected와 비교하여 **18/18 SHA-256 동일**하다.
증거는 `.runs/r20/protected-after.json`이다. 기준 manifest 생성 정당성은 미검증이다.
초기 git status는 깨끗했다. 변경은 지정 소스·신규 시험·본 보고서 세 파일뿐이다.
금지 파일·data·profiles·README는 변경하지 않았다.

## 설계 대비 차이

설계의 노드 오류 종료 원칙에 대해 이번 명시적 요구에 따라 플러그인 오류에만
규칙 폴백을 제공한다. False이면 호출자에게 예외가 전파된다.
기존 LLM 어댑터 내부의 폴백 정책은 이번 옵션의 대상이 아니다.
플러그인은 동기식 규칙 함수 계약이며 잘못된 반환 타입의 일반 검증은 추가하지 않았다.
ResearchRunner·공개 파사드·서비스에서 주입 인자를 노출하는 작업은 후속 연결 필요다.
이번 범위는 builder를 통한 직접 주입이며 독립 패키지 배포는 수행하지 않았다.

## 미검증

Python 실행 불가로 신규·기존 시험 통과, 실제 모델 품질·비용, 실제 Chroma 및
서비스 종단 연결은 미검증이다. 실제 모델 실행은 이번 범위에 없으며 LLM 호출을 하지 않았다.
플러그인 자체의 입력 불변성·마스킹·외부 통신 정책 준수는 호출자의 계약이다.

## 커밋

`git add`와 `git commit -m "feat: add research node plugin injection and rule fallbacks"`를
시도했으나 모두 `.git/index.lock: Permission denied`로 실패했다.
현재 샌드박스는 .git 쓰기를 허용하지 않아 커밋 해시는 없으며 미커밋 변경 0건 조건도
달성하지 못했다. 변경 세 파일은 보존한다. NightCoder의 쓰기 가능한 환경에서
시험 실행과 단일 커밋 수집이 필요하다. push·원격·브랜치 설정 변경은 하지 않았다.
