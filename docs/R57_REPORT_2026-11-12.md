# R57 보드 데모 보고서

## 구현

지정된 다섯 파일 안에서 구현했다. `scripts/board_demo.py`는 실제 run_baseline과
TraceResearchRunner를 사용한다. 기본 compare 연구 6문항과 법률 8문항을 네 설정,
k=1·3으로 실행하여 총 112개 이벤트를 생성하도록 구성했다. confirm은 사용하지 않는다.
graph_basic은 기존 설정과 같이 관점 분리·gap·rewrite를 끈다. graph_full은
RuleGrader, 마지막 설정은 기존 FakeLLMGrader의 골드와 무관한 고정 승인 큐를 쓴다.
새 대역 클래스를 만들지 않았다. 실제 모델·네트워크·임베딩 저장소를 사용하지 않는다.

R35/36 이벤트와 수집기를 통해 `.runs/events/<domain>/events.jsonl`에 추가 기록한다.
baseline은 run_trace.event_from_result를 사용한다. config는 설정 이름과 k를 포함한다.
실제 RELEVANCE 로그의 채점 횟수·통과 횟수로 grade를 채워 R37 집계에 연결한다.
법률 출력에는 실제 LegalFilter를 추가 적용하며 감사 코드만 보관한다.

R38 렌더러에 선택적 comparison sidecar 인자를 추가했다. 기존 호출과 기본 화면은
유지한다. 새 비교 표·품질 막대는 도메인·k별 네 설정, 골드 품질 항목 충족률,
종료 유형, 평균 루프·추정 토큰·가상 원가, R48 최초 검색 hit@k,
R44 독립 근거성 고정 문항 평가, R49 FakeJudge 점수·정답률을 표시한다.
R39 목표 파일이 있으면 기존 check_targets를 통해 목표 위반을 표시한다.
sidecar와 HTML은 `.runs/` 안에만 쓴다. 기존 이벤트는 삭제하지 않는다.

비율은 n과 Wilson 95% 구간을 표시한다. 평균은 n을 표시하며 Wilson 적용 대상이
아님을 명시한다. 모든 데모 수치는 합성 문항·규칙/가짜 모델 기준의 경로 시험이다.
실제 모델 결과와 혼합하지 않는다. injection ID는 비교 분모에서 제외한다.
HTML에 동적 텍스트와 속성을 이스케이프하며 빈 데이터는 미검증으로 표시한다.

## 시험

- 전체 시험 명령: `.venv/Scripts/python.exe -m pytest -q --basetemp=.runs/r57/pytest`
- tests not run here: the available repository Python has no pytest installed.
- 이 환경에서 시험 미실행: PATH에 python이 없고, 발견한 저장소 가상환경
  Python 3.15.2에는 pytest가 없어 전체 시험 명령을 시작할 수 없었다.
- 최종 전체 시험 집계: 실행 0건. passed/failed/error/skipped는 집계 불가이며
  0건 통과로 해석하지 않는다. 새 시험은 파라미터 확장 기준 9건을 작성했으나 미실행이다.
- 데모 시도: `.venv/Scripts/python.exe scripts/board_demo.py --out .runs/board_demo/index.html`
  → pydantic 부재로 import 단계에서 시작 불가. HTML 생성 및 1분 이내 실행은 미검증이다.
- Python 표준 compile 검사: 변경 Python 3개 문법 통과. 실제 import나 실행 통과를 뜻하지 않는다.
- 신규 시험은 실제 문항 팩·그래프·수집기·JsonlSink·필터·렌더러를 실행하며,
  도메인/k별 네 행, 이벤트 연결, 이스케이프, 빈 팩/빈 비교,
  injection 제외, 출력 경로 제한, 잘못된 k를 검사한다.
- 새 패키지 설치, 네트워크 접근, 모델 다운로드, LLM 호출, 기존 시험 수정·skip 추가 없음.

## 설계 대비 차이와 후속 연결 필요

설계의 연구 그래프와 주입식 grader 경계를 보존했다. 중앙 스키마·그래프 소스·기본값을
수정하지 않고 실행 조립과 표시만 scripts에서 수행했다. KNOWN_DEBT 증가 없음.

- human: 현재 RunEvent 종료 enum에 없어 후속 연결 필요. 0%로 대신 표시하지 않는다.
- 법률은 연구 그래프 실행 뒤 별도 도메인 필터 감사다. 법률 전용 graph verify·재시도
  연결은 후속 연결 필요. 감사 실패가 graph end_type을 소급 변경하지 않는다.
- R44는 그래프 출력이 아닌 별도 고정 문항의 보고서 검증기+grader 평가다.
  법률용 근거성 라벨 연결은 후속 연결 필요. 연구 baseline/basic 행의 독립 평가는
  해당 설정의 생성 출력 탐지율을 뜻하지 않는다.
- 연구 기본 문항에는 명시적 gold_sources가 없어 hit@k는 미검증이다.
  법률은 필수 조문 포함 문서 ID를 골드로 사용한다. 연구 골드 연결은 후속 연결 필요.
- R37 골드 보조 문서별 과차단 감사 라벨은 후속 연결 필요. 문서 탈락률은 실제
  채점 로그가 있는 전체 그래프에만 집계되며 반복 채점은 개별 관측이다.
- 판정기는 FakeJudge 어휘 점수다. 연구 참조는 지표명·반대 근거이며 법률은
  gold.answer다. 실제 의미 판정과 실제 모델 품질은 미검증이다.
- Chroma/memvid 저장소를 요구하지 않는 기존 keyword_search 실험 경로다.
  Chroma 실검색·실제 임베더 연결은 후속 연결 필요. 신규 memvid import 없음.
  버전 발행·롤백·해시 manifest 대체 구현 없음(Chroma 경로에 없음).

## 보존과 마무리

초기 git status는 깨끗했다. 보호 기준 `.runs/n10/protected-after.json`의 Expected
SHA-256과 작업 전후 18개가 모두 동일하다. 증거는
`.runs/r57/protected-before.json`, `.runs/r57/protected-after.json`이다.
data/profiles/frozen masking, 금지 소스, 기존 시험, README를 수정하지 않았다.
`git diff --check` 통과. push·원격/브랜치 설정 변경은 하지 않았다.

커밋 시도는 샌드박스가 `.git/index.lock` 생성을 Permission denied로 거부하여 실패했다.
현재 권한 설정이 `.git`을 읽기 전용으로 지정하고 승인 요청도 허용하지 않아 staging과
commit을 완료할 수 없다. 새 커밋 해시는 없다. 구현을 지우지 않고 지정된 다섯 파일의
미커밋 변경으로 보존했다. 따라서 미커밋 변경 0개 요구사항은 이 환경에서 미완료이며,
쓰기 권한이 있는 NightCoder 게이트에서 아래 명령으로 마무리해야 한다.

```powershell
git add -- scripts/board_demo.py scripts/metrics_board.py tests/test_board_demo.py docs/BOARD_DEMO.ko.md docs/R57_REPORT_2026-11-12.md
git commit -m "feat: add offline graph configuration board demo (R57)"
```
