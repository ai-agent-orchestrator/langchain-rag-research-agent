# E4~E8 실제 모델 결과 종합 — 2026-11-10 KST

## 판정 기준과 입력

결과 열람 전에 사용자 기준을 적용했다. 선택은 compare만 사용한다. E4/E5/E7은 Recall@3 → MRR → 오수용률 낮음 순이며 bootstrap 구간이 겹치면 차이 불확실이다. E6는 오수용 최소 → 오거절 최소 → 높은 임계값 순이다. confirm은 최종 선택 한 설정에 한 번만 보고하고 재선택하지 않는다. 모든 비율은 n과 Wilson 95% 구간을 함께 쓰며 n=0이면 비율/구간을 계산하지 않는다. injection은 검색 품질 분모에서 제외한다. 실제 모델과 fake 경로 시험을 별도 표로 둔다.

입력은 `.runs/e4`~`.runs/e8` 결과 파일만 읽었다. 재실행, 모델 다운로드, 임계값 재탐색은 하지 않았다. 기존 README의 memvid/E5 수치를 이번 Chroma E4~E8 결과로 옮겨 쓰지 않았다. 결과 파일이 없는 것은 실행 이력이 없다고 단정하는 대신 **이 입력에서 미실행/결과 없음**으로 표시한다.

**E4 — 지시문.** none/default/custom:Retrieve relevant legal passages의 E5와 BGE-M3 비교 출력은 있으나 모두 미준비다. 평가 문항 n=0이므로 Recall@3, MRR, 정답−근거 없음 점수 간격과 bootstrap 구간이 없다. 차이는 미검증이며 승자/권장 지시문을 정할 수 없다.

**E5 — 청크 크기.** 결과 파일이 없어 청크 크기·overlap별 실제 모델 평가 n=0이다. quote 경계 손실 및 토큰 한도 초과 수 역시 이 입력에서 확인되지 않는다. 과거 시험 성공이나 코드 기본값을 실측으로 대체하지 않는다. 차이는 미검증이다.

**E6 — 근거 없음 경계.** 저장된 격자/선택/confirm 결과가 없어 실제 n=0이다. 오수용/오거절 비율과 Wilson 구간은 산출 불가다. 기존 학습 세트의 근거 없음 9개라는 사용자 설명은 표본 부족의 배경이며, 실행 결과 n으로 채워 넣지 않았다. τ를 새로 탐색하거나 선택하지 않았다.

**E7 — 융합.** 방식별 결과 파일이 없어 실제 n=0이다. 유형별 Recall@3/MRR/오수용률, α와 RRF k의 차이는 미검증이다. 의미 검색·키워드·결합 중 어느 방식도 승자로 선언할 수 없다. confirm 비교도 하지 않았다.

**E8 — 작은 응용.** 실제 모델 n=0이다. 아래 fake 경로 시험은 파일 생성/계약 연결의 증거이며 의미적 중복 판별이나 요약 품질의 증거가 아니다. 유사도 REVIEW는 보조 정보이고 canonical guard의 BLOCK을 대체하지 않는다. injection은 검색 품질 분모에서 제외했다.

## 표본 부족과 골든셋 확장 제안

- 실제 E4~E8 평가 n=0: 모든 설정의 효과와 bootstrap 구간은 미검증이다. 우선 기존 세트의 compare 결과를 확보해야 하며 이번 작업에서 실행하지 않았다.
- 근거 없음: hard_negative와 off_topic을 우선 확장한다. 오수용 0건일 때 Wilson 95% 상한을 10% 미만으로 만들기 위한 산술적 최소는 **각 독립 split의 음성 n=35**다(0/35 상한 약 9.89%). 이는 0건을 예상하거나 보장하는 제안이 아니다. compare/confirm 각각 35개면 합계 70개이며, 기존 9개가 모두 독립·유효하게 유지될 때 최소 추가 61개다. 실제 split별 n이 없으므로 정확한 배분은 추가 확인이 필요하다. 최소 추가 수는 max(35−n_compare,0)+max(35−n_confirm,0)로 결정한다.
- 표현 차이(paraphrase), 전문어/정확 일치(legal_term), quote 경계/긴 quote, 복수 근거·multi_hop을 각각 **추가 20문항(새 compare 10, 새 confirm 10)**씩 제안한다. 최소 80개 추가이며 검정력 보장은 아니다. 길이/청크와 유형 태그를 함께 기록해 중복 집계를 피한다. 유형별 n을 확보한 뒤 필요한 수를 다시 설계해야 한다.
- injection은 별도 정책 세트로 **추가 40개(공격 20, 정상 유사 문장 20)**를 제안한다. 검색 품질 골든셋 분모에 넣지 않으며 탐지/오경보 보정 전에는 정책 대체 주장을 하지 않는다.
- 중복 병합과 감량은 사람이 판정한 중복/비중복 쌍 각 **추가 20쌍**, 필수 사실/보호 문장이 라벨된 긴 프롬프트 **추가 20개**를 제안한다. 현재 fake probe n=1과 후보 0건만으로 일반화할 수 없다.

이 문항 수는 수집 시작을 위한 제안이다. Wilson 음성 표본 하한 이외의 숫자는 통계적 검정력 계산으로 도출한 수가 아니다. 새 골든셋은 이번에 작성하지 않았으며 작성한다면 .runs에만 둔다.
