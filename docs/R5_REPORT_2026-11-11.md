# R5 — 리서치 그래프용 Chroma 검색 어댑터

## 무엇을 고쳤나

`rag/research_chroma.py`의 `make_chroma_search(index, embedder, *, rule=None, masker=None)`는 실제 `ChromaIndex`와 기존 `Embedder` 프로토콜을 받아 `SearchFn`을 만든다. 반환값은 순위순 `(chunk_id, masked_text)` 목록이다. 같은 문서의 다른 청크가 ResearchRunner에서 합쳐져 사라지지 않도록 출처 ID에는 청크 ID를 사용한다. 호출자가 인덱스와 임베더를 만들고 인덱스를 닫는다. 어댑터는 모델을 로딩하거나 저장소를 발행하지 않는다.

양수 k는 결과 개수 상한이며 컬렉션 크기로 제한한다. k가 0 이하이거나 컬렉션이 비었으면 빈 목록을 반환한다. 정수가 아닌 k와 bool, 임베더 차원 불일치, 벡터 모드가 아닌 규칙과 비유한 임계값은 거절한다. 임베딩·검색·마스킹 예외를 빈 검색 결과로 바꾸지 않는다.

선택적인 `RelevanceRule`은 기존 `retrieve/gate.py`의 `to_result`를 그대로 사용한다. 문서별 최고 점수의 절대 임계값과 상위 두 문서 점수 차를 판정한 뒤 k개로 자른다. k=1이거나 상위 여러 청크가 같은 문서여도 두 번째 문서를 놓치지 않도록 게이트 사용 시 전체 청크 후보를 요청한다. 이는 대형 컬렉션에서 비용이 크며 성능은 미검증이다. 규칙을 생략하면 게이트 없이 top-k를 반환한다. 임계값 보정이나 설정 선택은 수행하지 않았다.

`Masker.mask`를 주입하면 임베딩 전 쿼리와 반환 직전 본문에 적용한다. 원본 Chunk는 수정하지 않는다. masker를 생략하면 호출자가 쿼리와 `safe_text`를 미리 마스킹해야 한다. 출처 ID는 변경하지 않으므로 개인정보가 없는 ID를 공급해야 한다. frozen masking은 수정하지 않았다. 신규 모듈의 MATURITY는 incubating이며 rag 조립 계층에서 기존 구현을 연결한다. KNOWN_DEBT는 변경하지 않았다.

## 시험

`tests/test_research_chroma.py`에 정적으로 집계한 19개 **경로 시험**을 작성했다. 기존 `FakeEmbedder`, 실제 영속 Chroma, 실제 `ResearchRunner`와 컴파일된 LangGraph를 사용한다. 가짜 저장소나 그래프로 대체하지 않는다. 시험 컬렉션은 실행마다 고유한 `.runs/r5/chroma-tests/` 하위 폴더에 생성하며 종료 시 인덱스를 닫는다. 합성 전화 값은 허용된 `010-0000-0000`만 사용한다.

- 반환 형식·청크 ID·k 상한, 비양수/비정수 k, 빈 컬렉션.
- 절대 임계값 통과/거절, k=1에서도 다른 문서의 동점에 의한 gap 거절.
- 한 문서의 여러 청크 뒤에 있는 두 번째 문서를 놓치지 않는 회귀 시험, 동일 문서 청크끼리는 gap 경쟁자로 보지 않는 시험.
- 기존 frozen `mask_pii`를 호출하는 Masker 주입으로 쿼리와 본문 마스킹, 원본 보존.
- 차원 불일치, 잘못된 게이트, 실제 FakeEmbedder의 빈 입력 오류 전파.
- Runner의 검색→추출→작성→검수, 인용·span 일치와 마스킹된 출처, 게이트 거절 후 출처·claim이 없는 EMPTY_REPORT.

## 대표 PC에서 실제 E5로 실행할 명령 — 실행하지 않음

이미 필요한 패키지와 모델이 설치·캐시된 PC에서만 아래를 실행한다. 마지막 인수 `LOCAL_CACHED_E5_REVISION`을 캐시에 있는 정확한 모델 커밋 revision으로 바꾼다. 다운로드·LLM 호출은 포함하지 않는다. 아래는 합성 자료를 실제 E5로 연결하는 실행 명령이며 품질 평가나 게이트 보정 명령이 아니다. `rule`은 생략하며 보정된 임계값이 필요하면 compare 자료로 별도 보정 후 주입해야 한다.

```powershell
$env:HF_HUB_OFFLINE = '1'
$env:TRANSFORMERS_OFFLINE = '1'
$env:LANGSMITH_TRACING = 'false'
$env:LANGCHAIN_TRACING_V2 = 'false'
$env:PYTHONPATH = 'src'
@'
from pathlib import Path
from uuid import uuid4
import sys
from rag_research_agent.core.contracts import Chunk
from rag_research_agent.embed.providers import E5Embedder
from rag_research_agent.rag.research_chroma import make_chroma_search
from rag_research_agent.rag.research_graph import ResearchConfig, ResearchRunner
from rag_research_agent.store.chroma_store import publish_chroma

embedder = E5Embedder(revision=sys.argv[1], device='cpu')
text = '주택 거래량은 18% 감소했다.'
chunk = Chunk('doc-a1', 'chunk-a1', 'v1', 'synthetic', 'Synthetic', text,
              embedder.count_tokens(text), 'ck1', 'm1', 'p1')
out = Path('.runs/r5/e5-pc') / uuid4().hex
index = publish_chroma([chunk], embedder.encode_documents([text]),
                       path=out / 'chroma', collection='research-e5',
                       dimension=embedder.dimension)
try:
    search = make_chroma_search(index, embedder)
    result = ResearchRunner(search, ResearchConfig(k=1, stance_split=False,
                            auto_metrics=False)).run('주택 거래량을 정리해 주세요.', ('주택 거래량',))
    (out / 'report.txt').write_text(result.report, encoding='utf-8')
    print(result.report)
    print(result.verify_codes)
finally:
    index.close()
'@ | python - LOCAL_CACHED_E5_REVISION
```

## 고치지 않은 것과 이유 / 미검증

실제 E5 실행·품질·지연, Chroma 동시 검색 안전성, 영속 인덱스와 모델 revision·normalization의 일치 여부는 미검증이다. 현재 ChromaIndex가 공개하는 차원만 자동 확인하며 나머지 일치는 호출자 책임이다. `to_result`의 내부 버전 필드에는 컬렉션 이름을 전달하지만 이를 버전 발행이나 해시 manifest 검증으로 주장하지 않는다. 버전 발행·롤백·해시 manifest 기능은 Chroma 경로에 없음. 어댑터에서 대체 구현하지 않았다.

서비스·CLI·설정 파일 연결은 허용 범위 밖이므로 후속 연결 필요다. 기존 시험·기대값·skip, 금지 파일·data·profiles·README는 수정하지 않았다. 실제 모델·LLM·네트워크·LangSmith 업로드·패키지 설치·push·원격/브랜치 설정 변경은 수행하지 않았다.

## TESTS 게이트 재시도 수정

전달받은 이전 게이트 결과는 **613 passed / 1 failed / 0 error / 1 skipped / 10 deselected**이다. 실패 시험 이름과 traceback은 제공되지 않아 그 실패와 아래 결함이 동일한지는 미검증이다.

실제 `FakeEmbedder(dimension=64)`는 빈 문자열과 공백 전용 문자열도 빈 bigram으로 해싱하여 L2 단위 벡터로 만든다. 따라서 기존 `test_embedding_error_propagates`가 요구하는 빈 쿼리의 `EmbeddingError`를 임베더에 맡기면 예외가 발생하지 않는다. 로컬 Python으로 빈 문자열, 일반 공백, 탭·줄바꿈, 전각 공백의 벡터 제곱합이 모두 1임을 확인했다. 근거: `.runs/r5/retry-static-check.txt`.

`make_chroma_search`가 마스킹 후 비어 있거나 공백뿐인 쿼리를 임베딩 전에 `EmbeddingError`로 거절하도록 수정했다. 오류 메시지는 기존 시험이 요구하는 `L2-normalized` 설명을 유지한다. k가 0 이하이거나 컬렉션이 비어 있으면 기존대로 빈 목록을 반환한다. 기존 시험의 기대값은 바꾸지 않았다. 일반 공백·탭/줄바꿈·전각 공백 각각을 게이트 사용/미사용으로 검증하는 회귀 시험 6개를 추가했다. 실제 FakeEmbedder와 영속 Chroma fixture를 그대로 사용하며 대체 저장소나 그래프는 만들지 않았다. R5 경로 시험은 정적 집계 합계 25개다.
