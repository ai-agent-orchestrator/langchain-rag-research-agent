# R8 보고서 — 손잡이 정의서·격자·보드 선택기

## 무엇을 고쳤나

- `evals/research/knobs.json`: k=1/2/3, max_rewrites=0/1/2, max_gap_rounds=0/1/2, use_checklist=true/false의 이름·설명·후보값·기본값·맞바꾸는 것을 정의했다. 기본값은 실제 ResearchConfig의 2/2/2/true와 같다.
- `scripts/research_grid.py`: 54개 조합을 실제 ResearchConfig·ResearchRunner·keyword_search와 기존 score/aggregate로 실행한다. compare만 사용하며 type=injection 문항은 제외한다. confirm 평가·설정 자동 선택은 하지 않는다. 입력에 compare 문항이 없으면 오류로 중단한다.
- `.runs/research_eval/grid.json` 형식은 schema_version, 시각, git SHA, split, dataset, 경로 시험·추정 토큰 표시, 손잡이 정의·기본값, entries 배열이다. 각 entry는 선택값, 전체 실행 설정, 집계, 문항별 점수·보고서·추정 토큰·루프·로그를 담는다. 항목별 비율은 기존 집계의 표본 수와 Wilson 95% 구간을 보존한다. 품질은 기존 네 항목 비율의 평균이다.
- `scripts/research_board.py`: 손잡이별 선택 컨트롤과 설명을 추가했다. 변경 즉시 사전 계산된 조합의 품질·항목별 점수·추정 토큰·루프 및 기본값 대비 차이를 표시한다. 전체 실행 설정 JSON은 선택·복사할 수 있는 텍스트로 표시한다. true/false 타입을 보존한다. 없는 조합은 미검증으로 표시한다.
- render()는 기존 호출에서도 격자 파일이 있으면 자동으로 읽는다. grid 인자로 명시적으로 전달할 수도 있다. 격자가 없으면 생성 명령을 안내하며, runs 기록이 없어도 격자 영역을 사용할 수 있다. 격자 CLI는 grid.json 저장 후 기존 runs.jsonl을 보존하면서 board.html을 재생성한다. JSON 종료 태그를 escape하며 페이로드 안의 템플릿 표식도 그대로 보존한다.

실행 명령(네트워크·모델 호출 없는 규칙 기반 경로 시험):

```powershell
python scripts/research_grid.py
```

## 시험

신규 `tests/test_research_grid.py`에 시험 6개를 추가했다. 조합 수·유일성·기본값·타입, 실제 runner를 거친 CLI 출력 형식과 점수 재집계, confirm/injection 제외, 루프 0 상한, compare 없음 오류, 격자·기록 없이 렌더, 자동 파일 연결, 종료 태그·표식 보존, 실제 JavaScript 함수의 54개 선택·기본값 차이·없는 조합·불리언 타입을 검사한다. runner나 DOM의 가짜 대체 클래스는 사용하지 않는다. 제외 회귀 시험의 confirm/injection 문항은 docs/gold가 없어 잘못 실행하면 실패하도록 구성했다.

전체 시험 명령:

```powershell
python -m pytest -q -p no:cacheprovider --basetemp=.runs/r8/full-tmp
```

tests not run here: Python executable is unavailable (CommandNotFoundException).
이 환경에서 시험 미실행: PATH의 python/python3/py와 저장소 .venv-python/.venv-cache 안에서 Python 실행기를 찾지 못했다. 위 전체 시험 명령은 시작하지 못했다. pytest 실행 0건이며 passed/failed/error/skipped 집계는 불가하다. 신규 6개 시험과 실제 54개 runner 실행도 미검증이며 NightCoder 게이트에서 확인해야 한다.

별도 Node.js 검증:

- 실제 TEMPLATE에서 추출한 전체 JavaScript에 `node --check .runs/r8/board.cjs`를 실행해 통과했다.
- 실제 gridEntry/gridResult 함수에 합성 결과표를 전달해 54개 선택, 기본값 차이, 없는 조합, 불리언과 문자열 구분, 표본 수·Wilson 구간 표시를 `node .runs/r8/selection.cjs`로 검증해 통과했다. 최초 보조 검증 명령은 PowerShell→Node 파이프의 한글 인코딩 손실로 문자열 단언 1개가 실패했고, 검증 문자열을 Unicode escape로 교정한 뒤 동일 함수 검증을 통과했다. 제품 코드를 가짜 구현으로 대체하지 않았다.

이는 보드 출력 경로 시험이며 실제 runner 실행, pytest 집계, 모델 품질 결과를 대체하지 않는다. 결과 파일은 `.runs/r8/`에만 기록했다. `git diff --check` 통과.

## 고치지 않은 것과 이유 / 미검증

Python 부재로 grid.json 실측 결과는 생성하지 않았다. 브라우저의 실제 컨트롤 조작·시각 배치는 미검증이다. 실제 모델·LLM 호출·네트워크·다운로드·패키지 설치는 수행하지 않았다. 모델 실행 명령은 이번 작업의 실행 금지 범위에 따라 추가하지 않았다. 저장소 어댑터 연결은 변경하지 않았으며 기존 합성 corpus의 keyword_search 경로를 사용한다. Chroma를 다른 저장소로 바꾸거나 memvid 의존성을 추가하지 않았다.

변경은 지정된 5개 파일뿐이다. 기존 시험·기대값·skip·KNOWN_DEBT, README, data/profiles, tracing, memvid, frozen masking을 수정하지 않았다. 보호 파일 18개 SHA-256은 기존 `.runs/n10/protected-after.json`의 Expected와 18/18 동일하며 증거는 `.runs/r8/protected-after.json`이다. 초기 git status는 깨끗했다. push·원격·브랜치 설정 변경은 하지 않았다.
