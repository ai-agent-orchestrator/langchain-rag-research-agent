# R19 — 리서치 모듈 공개 API

## 구현

구조 시험을 먼저 확인했다. `test_modules_do_not_import_each_other_except_through_core`는
조립 계층 rag 외의 패키지가 rag·guard를 직접 import하는 것을 허용하지 않는다.
따라서 요청의 대체 경로 `src/rag_research_agent/rag/research_api.py`를 선택했다.
research 패키지는 만들지 않았으며 KNOWN_DEBT와 기존 시험은 변경하지 않았다.

API_VERSION 0.1, run_research, 기존 ResearchConfig·ResearchResult·SearchFn·keyword_search,
DomainFilter·register·get_filter, 기존 make_chroma_search의 공개 별칭 chroma_search를 제공한다.
클래스·검색 구현은 복제하지 않고 기존 객체를 re-export한다. 그래프 관련 이름은 지연 로딩한다.
MATURITY는 incubating이다. 새 memvid 의존성이 없다.

기본 research는 ResearchRunner의 설정·실행 결과를 그대로 반환한다.
다른 등록 도메인은 실제 필터의 입력 검사 → 기존 그래프 → 도메인 검수 → 고지 순서로 연결한다.
입력 차단 시 검색하지 않으며 검수 실패 시 안전 문구와 오류 코드를 반환한다.
성공한 report에만 finalize를 적용하고 draft는 원래 인용 문장으로 유지한다.
실험 보드·기존 서비스·모델·설정 기본값은 수정하지 않았다.

변경 파일은 네 개다.

- `src/rag_research_agent/rag/research_api.py`
- `tests/test_research_public_api.py`
- `docs/RESEARCH_API.ko.md`
- `docs/R19_REPORT_2026-11-11.md`

## 시험

신규 시험은 매개변수 포함 9건을 정의했다. 공개 이름 import·기존 객체 동일성,
문서의 독립 Python 예제 3개 직접 실행, 기본 Runner 결과 동일성, 실제 LegalFilter의
검색 전 차단과 검수 실패, 실제 필터 팩토리 등록, 미등록 도메인 오류,
선택 의존성을 차단한 별도 프로세스의 파사드 import를 검사한다.
새 대체 그래프·대체 필터는 없다. Chroma 예제는 실제 publish_chroma·ChromaIndex와
기존 FakeEmbedder를 사용하는 **경로 시험**이다. 실제 모델 품질 평가와 섞지 않는다.
문서와 신규 시험에는 개인정보 모양의 값을 넣지 않았다.

전체 시험 시도 명령:

```powershell
python -m pytest -q -p no:cacheprovider --basetemp=.runs/r19/full-tmp --junitxml=.runs/r19/full-pytest.xml
```

**tests not run here: Python is not available on PATH.**

이 환경에서 시험 미실행: python 명령을 찾지 못했다. py·pytest도 PATH에 없으며
저장소 .venv-python·.venv-cache에서 python.exe를 찾지 못했다.
실행 0건, passed/failed/error/skipped는 미실행으로 집계 불가다.
JUnit 결과는 없으며 신규·기존 시험 통과를 주장하지 않는다. NightCoder 게이트 판정이 필요하다.
시험 시도 기록은 `.runs/r19/test-attempt.txt`에 둔다.

## 설계 대비 차이

RESEARCH_GRAPH_DESIGN의 주장 단위 검수와 루프는 기존 그래프 그대로 사용한다.
기본 research 경로에 별도 DomainFilter.verify를 추가하면 기존 결과가 달라질 수 있어 추가하지 않았다.
다른 도메인은 파사드 바깥 관문으로 한 번 검수하며 retryable 오류도 추가 루프를 돌리지 않는다.
도메인별 그래프 내부 검수·재시도·branch별 검색 격리는 **후속 연결 필요**다.
기존 노드 내부 리서치 검수는 다른 도메인에서도 실행된다. 도메인 고지는 report에만 붙는다.

LangChain/LangGraph 없이 모듈·도메인 계약 import가 가능하도록 지연 로딩했다.
기존 ResearchConfig 등이 있는 research_graph 자체가 LangGraph를 import하므로
모든 공개 이름의 import 및 그래프 실행에는 기존 선택 의존성이 필요하다.
이 의존성 분리는 허용된 수정 범위 밖이므로 **후속 연결 필요**다.
LLM·체크포인터 인자가 필요한 config는 기존 ResearchRunner에서 사용한다.
파사드에 새 모델 로딩이나 세션 인터페이스를 만들지 않았다.
