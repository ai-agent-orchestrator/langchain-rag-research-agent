# N14 보고서 — 대화 이력 기반 규칙 질의 재작성

2026-11-10 KST. AGENTS.md를 먼저 읽고 현재 저장소·브랜치 `nc/rra-codex`에서 작업했다. NightCoder 규칙을 적용하며 push·원격·브랜치 설정 변경은 하지 않는다.

## 구현

- `rag/history_rewrite.py`에 `rewrite_with_history(query, history, *, max_turns=3) -> tuple[str, list[str]]`를 추가했다. history는 오래된 순서부터 정렬된 사용자 질의 문자열 목록이다. 최신 N턴만 고려하며 직전 질의에서만 키워드를 얻는다. 0턴은 비활성화, 음수는 ValueError다. 직전 질의가 비어 있거나 키워드가 없어도 더 오래된 주제로 대체하지 않는다.
- 지시어(그거·그건·그것·그게·이것·이거·이건·해당·위의 및 조사 결합)를 감지하거나 공백 제외 10자 이하의 짧은 질의이면 기존 `core.lexical.lex_terms`로 직전 질의의 키워드를 추출해 덧붙인다. 현재 질의에 이미 있는 키워드와 이전 질의의 중복 키워드는 추가하지 않는다. 지시어 없이 10자를 넘는 질의는 그대로 반환한다. 형태소 분석이나 의미 기반 핵심어 추출은 하지 않는다.
- 원문 문자열을 공백·탭까지 그대로 접두사로 보존한다. 적용 이유는 `demonstrative`, `short_query` 순서의 목록이며 둘 다 해당하면 둘 다 반환한다. 실제 키워드 추가가 없으면 이유 목록은 비어 있다. 빈 현재 질의는 그대로 반환한다. 입력 이력을 수정하지 않는다.
- 모듈 docstring에 개인정보 마스킹은 호출자 책임이라고 명시했다. `MATURITY = "incubating"`을 선언하고 표준 라이브러리와 core만 사용한다. LLM·네트워크·모델·저장소 호출 및 memvid 의존성을 추가하지 않았다. Chroma 개발 기본값과 KNOWN_DEBT를 유지한다.
- GuidancePipeline에는 연결하지 않았다. 호출자의 마스킹 완료 이력 공급과 실제 검색 경로 적용에는 후속 연결 필요다.
