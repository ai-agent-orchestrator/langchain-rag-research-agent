# R9 보고서 — 한국어 README 현황 정리

## 무엇을 고쳤나

- `README.ko.md`의 Equalizer 핵심 기능을 “설계 / 구현 전”에서 “규칙 기반 구현”으로 정정했다. `ontology/rule_labeler.py`의 RuleLabeler, `rag/brief.py`의 실제 Parts 연결, `rag/stages.py`의 점수 혼합·보호 후보·다이어트, `rag/equalizer_graph.py`의 StateGraph 연결을 확인했다. 기존 `tests/test_equalizer_v0.py`·`tests/test_equalizer_graph.py`의 관련 검사도 확인했다. 시험 정의의 존재와 실행 통과를 구분했다.
- LangGraph 가드레일·교체형 도메인 필터와 규칙 기반 리서치 그래프·평가 보드 행을 추가했다. 구현과 실제 모델 품질을 구분하고, 가짜 임베더 결과를 경로 시험으로 명시했다. memvid 수치는 과거 기록이며 신규 개발 기본값은 Chroma임을 적었다.
- 영문 README 맨 위와 같은 설계 변경 블록은 한국어 README 맨 위에 이미 있었다. 중복 삽입하지 않고 유지했으며, `GuardrailLimits.max_loops=3`과 라우팅 조건에 맞춰 도식의 한도를 “RAG 실행 총 3회”로 명확히 했다.
- 리서치 그래프·도메인 필터·실험 보드 문서 세 개를 한 단락으로 소개했다. `rag/research_graph.py`, `guard/domain_filter.py`, `scripts/research_eval.py`, `scripts/research_board.py`에서 확인한 규칙 기반 경로·계약·추정 토큰·Wilson 구간만 설명했다. 그래프의 검색은 keyword_search이며 Chroma 어댑터와 실제 모델 작성기는 후속 연결 필요로 표시했다.

## 시험

전체 시험 명령:

```powershell
python -m pytest -q -p no:cacheprovider --basetemp=.runs/r9/full-tmp
```

tests not run here: Python executable is unavailable (CommandNotFoundException).

이 환경에서 시험 미실행: PATH의 python/python3/py 및 저장소 .venv-python/.venv-cache에서 Python 실행기를 찾지 못했다. 전체 시험 명령은 시작하지 못했다. pytest 실행 0건, passed/failed/error/skipped 집계 불가. NightCoder 게이트의 전체 시험 판정이 필요하다.

문서 결함의 회귀 검사는 허용 파일 범위 안에서 PowerShell로 실행했다. 실제 README를 읽어 상단 설계 변경 블록 위치, 오래된 “검수 완료, 구현 전” 문구 제거, 규칙 기반 구현 표시, 실제 모델 품질 미검증 표시, 세 문서의 링크와 대상 존재를 단언했다. 7 passed / 0 failed. 이는 문서 검사이며 pytest 결과나 모델 품질 측정이 아니다. 별도 시험 파일은 지정된 두 파일 범위를 벗어나므로 추가하지 않았다. 기존 기능 시험·기대값·skip은 변경하지 않았다.

`git diff --check` 통과. 보호 파일은 기존 `.runs/n10/protected-after.json`의 Expected와 SHA-256을 비교하여 18/18 동일을 확인했다. 증거: `.runs/r9/protected-after.json`. 초기 git status는 깨끗했다.

## 고치지 않은 것과 이유 / 미검증

변경은 README.ko.md와 이 보고서뿐이다. README.md, 금지 소스, data/profiles, 기존 시험, KNOWN_DEBT는 변경하지 않았다. 새 모듈·기능·대체 클래스는 만들지 않았다. 역사적 평가 수치는 다시 측정하거나 변경하지 않았다. 문서만 정리하는 범위이므로 모델 실행 명령을 추가하지 않았다. 실제 모델·LLM 호출·네트워크·모델 다운로드·패키지 설치·confirm 재평가는 수행하지 않았다. 실제 모델 품질과 전체 시험 통과는 미검증이다. push·원격·브랜치 설정 변경은 하지 않는다.

## 커밋 제약

`git add -- README.ko.md docs/R9_REPORT_2026-11-11.md`와 `git commit -m "docs: refresh Korean README implementation status"`를 각각 시도했으나 모두 `fatal: Unable to create 'C:/work/rra-codex/.git/index.lock': Permission denied`로 실패했다. 이 샌드박스의 .git은 읽기 전용이며 권한 상승은 허용되지 않는다. 커밋 해시는 없고 미커밋 변경 0건 조건은 충족하지 못했다. 작업을 삭제하지 않고 보존한다.
