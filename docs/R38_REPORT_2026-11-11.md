# R38 계측 보드 4패널

## 구현

AGENTS.md, METRICS_BOARD.ko.md 이벤트 스키마와 RESEARCH_GRAPH_DESIGN,
DOMAIN_FILTERS, LANGGRAPH_GUARDRAIL 설계 및 test_structure 규칙을 확인했다.
변경은 scripts/metrics_board.py, tests/test_metrics_board.py, 본 보고서뿐이다.

- `.runs/events/*/events.jsonl`의 완전한 run 레코드를 실제 core.RunEvent로
  검증한다. nodes는 run 내부 배열이다. 파일 순서를 고정하고 빈 줄은 무시한다.
  중복 run_id·잘못된 레코드는 거부하며 오류에 원본 데이터는 출력하지 않는다.
- 실행 궤적: 경로 빈도, END/give_up/cutoff 비율, rewrite 회전수 분포.
- 비용 통제: SLM/Flagship 호출 수, 입력/출력 토큰, 총·건당 cost_krw,
  Fast/Deep 비율. 가격 재계산 없이 생산자가 기록한 원가를 사용한다.
- 환각 방어: 실제 R37 aggregate_guard_audit 호출. 문서 가중 relevance 탈락률,
  코드별 발생 횟수·reason, 골드 대비 과차단 의심과 골드 실행 수를 표시한다.
  render의 gold/injection_run_ids 인자는 기존 R37 계약을 따른다.
  CLI는 반복 가능한 --injection-run-id로 품질 분모 제외를 받는다.
- 레이턴시: 노드 호출당 평균 ms를 인라인 SVG 막대로, TTFT·전체 실행 시간을
  실행당 평균과 표본 수로 표시한다. 노드 미계측과 빈 입력은 명시한다.
- 도메인 선택 탭, 자동/밝은/어두운 테마, 모바일 단일 열과 줄바꿈 CSS.
  데이터는 서버 측 HTML 이스케이프하며 JavaScript에 삽입하지 않는다.
  외부 라이브러리·CDN·네트워크·모델 호출 없이 HTML 하나를 생성한다.
- estimated=true/false는 같은 도메인에서도 별도 4패널 묶음이다.
  estimated=false도 실제 모델 품질 입증으로 해석하지 않는다.
  비율은 분자/분모와 Wilson 95% 구간을 표시하고 빈 분모는 미검증이다.
  관측 0건을 보장으로 쓰지 않는다.

기존 기본 동작은 변경하지 않고 CLI 또는 render 호출로만 실행한다.
표준 라이브러리·core 계약·rag 집계에만 의존하는 스크립트이며
MATURITY=incubating이다. KNOWN_DEBT, 기존 시험, memvid 코드는 변경하지 않았다.

```powershell
python scripts/metrics_board.py
python scripts/metrics_board.py --injection-run-id run-inj
```

기본 결과는 `.runs/metrics_board/index.html`이며 --output도 `.runs/` 내부만 허용한다.

## 시험

신규 시험은 매개변수 확장 포함 **12개 사례**다(실행 수가 아닌 정의 수).
합성 이벤트를 실제 RunEvent/NodeEvent와 R37 집계·HTML 렌더러·JSONL/CLI에
통과시키는 경로 시험이다. 모델·임베더 대역은 만들지 않았다.
두 도메인의 탭과 지표 분리, 4패널, 빈 입력, HTML/속성/script 종료 태그
이스케이프, 추정/비추정 분리, 노드 시간 평균, 골드와 injection 제외,
JSONL 왕복, 잘못된 이벤트·중복 실행 거부, 출력 경로 제한,
테마·모바일 CSS 및 외부 자원 부재를 검사하도록 작성했다.
개인정보 형태의 시험 값은 사용하지 않았다.

전체 시험 명령(NightCoder memvid 제외 정책):

```powershell
python -m pytest -q -m "not memvid" -p no:cacheprovider --basetemp=.runs/r38/pytest-temp
```

**이 환경에서 시험 미실행: Python 실행기를 찾을 수 없음.**
tests not run here: Python executable is unavailable in this sandbox.
passed/failed/error/skipped: 모두 미집계(수집·실행 시작 불가).
사유 기록은 `.runs/r38/full-tests.txt`다. NightCoder 게이트에서 실행 판정이 필요하다.
시험 시작 실패 후 작업은 보존했다.

## 설계 대비 차이·후속 연결 필요

정본 예시 및 R35 계약처럼 nodes를 run 안에 담는 JSONL을 읽는다.
별도 node 레코드는 run_id 연결 스키마가 없으므로 임의로 합치지 않는다.
실시간 수집·Spring Boot/FastAPI 콜백은 이 작업 범위 밖이며 후속 연결 필요다.
목표선 설정 파일·초과 경고는 R38 지정 4패널 범위에 포함하지 않았다.
건당 원가는 가격표로 이미 환산된 cost_krw를 표시한다.
골드 sidecar의 CLI 파일 포맷은 만들지 않고 render의 실제 GoldEvidence 주입을
지원한다. CLI 골드 파일 연결은 후속 연결 필요다.
guard reason은 생산자가 이미 마스킹해야 하며 HTML 이스케이프는 개인정보
마스킹을 대신하지 않는다. injection ID도 생산자/호출자가 명시해야 한다.

## 미검증·보호 확인·커밋

시험 통과, 실제 브라우저의 모바일 폭·테마·탭 조작, 실제 모델 품질·가격·TTFT,
운영 이벤트 생산자의 계측 정합성은 미검증이다. 실제 모델 실행이 필요한
기능이 아니므로 실제 모델 실행 명령은 없다. 모델 다운로드·LLM 호출·패키지
설치·네트워크 접근은 수행하지 않았다.

기준 `.runs/n10/protected-after.json` Expected와 작업 전후 파일을 비교해
**18/18 SHA-256 동일**을 확인했다. 증거는 `.runs/r38/protected-before.json`,
`.runs/r38/protected-after.json`이다. 기준 manifest 자체의 정당성은 미검증이다.
금지 파일, README, data/profiles, 기존 보드는 변경하지 않았다.
초기 작업 트리는 깨끗했다. git diff --check 통과 및 신규 파일 줄 끝 공백을 확인했다.
결과·시험 증거는 .runs/r38에만 쓴다. push·원격·브랜치 설정 변경은 하지 않았다.

현재 nc/rra-codex에서 git add를 시도했으나 `.git/index.lock: Permission denied`로
실패했다. 샌드박스는 .git 쓰기를 허용하지 않고 권한 상승도 허용하지 않는다.
커밋 명령도 같은 이유로 실패했다. **커밋 해시 없음. 지정 세 파일은 미커밋으로
보존되며 미커밋 변경 0건 조건을 달성하지 못했다.** Git 쓰기가 가능한 NightCoder
환경에서 시험 후 단일 커밋으로 수집해야 한다.
의도한 커밋 메시지: `feat: render four-panel metrics board (R38)`.
