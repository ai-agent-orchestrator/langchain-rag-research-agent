# R17 — 실제 리서치 그래프 Mermaid 내보내기와 설계 현황

## 구현

- `scripts/research_graph_diagram.py`는 실제 `build_research_graph(keyword_search({}), cfg)`를 컴파일하고
  `.get_graph().draw_mermaid()`의 반환 문자열을 UTF-8/LF로 저장한다. 기본 저장 대상은
  `docs/diagrams/research_graph.mmd`다. `--output`으로 저장 위치를 지정할 수 있다.
  실제 keyword_search를 주입하지만 그래프를 실행하지 않아 검색·임베딩·모델·네트워크 호출이 없다.
  새 의존성이나 가짜 그래프·렌더러를 추가하지 않았다. 기본 ResearchConfig와 제품 동작은 변경하지 않았다.
- 설계 문서 7·8절을 실제 소스 기준으로 갱신했다. R3 검색 호출 비용, R6 병렬 분기,
  Chroma SearchFn 어댑터, R7/R8 보드·compare 격자, R10/R11 구조화 출력,
  R12 선택적 문장 대조, R13 체크포인트·계획 검토, R14 가드레일 어댑터,
  R15 refine 옵션의 존재와 미연결 부분을 구분했다. R9의 문서 변경 자체를 기능 구현으로 세지 않았다.
  R16 별도 보고서·구현 표식은 현재 저장소에서 확인하지 못해 완료로 기록하지 않았다.
- 기본 실제 그래프의 순차 retrieve와 조건부 병렬 노드를 구별하고,
  상위 가드레일과 내부 연구 그래프를 구분했다. 생성 대상 Mermaid 파일을 링크했다.

## 시험

신규 `tests/test_research_diagram.py`에 5건을 정의했다.

- 순차/병렬 × stance_split 켜짐/꺼짐 4건: 실제 그래프의 전체 노드 선언과 기대 노드 집합을 확인하고,
  스크립트 반환값·저장 내용이 실제 `draw_mermaid()` 결과와 같은지 검사한다.
- CLI 1건: 저장소 밖 작업 디렉터리에서 실제 Python 스크립트를 호출하고 `--output` 결과와
  실제 기본 그래프 Mermaid의 일치를 검사한다. pytest 임시 경로는 아래 명령에서 `.runs/`로 지정한다.

전체 시험 실행 명령:

```powershell
python -m pytest -q -p no:cacheprovider --basetemp=.runs/r17/full-tmp --junitxml=.runs/r17/full-pytest.xml
```

**tests not run here: Python is not available on PATH.**

이 환경에서 시험 미실행: `python` 명령이 CommandNotFoundException으로 시작되지 않았다.
`python`·`py`·`pytest`가 PATH에 없고 저장소 `.venv-python`·`.venv-cache`에서도 Python 실행 파일을
찾지 못했다. 실행 0건이며 passed/failed/error/skipped는 미실행으로 집계 불가다.
새 5건과 전체 시험의 판정은 NightCoder 게이트에서 수행해야 한다.
실행 시도 기록은 `.runs/r17/test-attempt.txt`다. JUnit 결과는 생성되지 않았다.

## 설계 대비 차이

요청한 실제 그래프 내보내기 API를 그대로 사용한다. 다이어그램 기본 설정은 현재 기본 그래프를 나타내며,
선택적인 병렬 분기는 Python 함수의 cfg 인자로 검사한다. 상위 가드레일이나 옵션 노드를 기본 그래프에
임의로 합치지 않았다. 설계 1~6·9~10절은 이번 지정 갱신 범위 밖이므로 그대로 두고,
7절에 구현과 개요 설계의 차이를 명시했다.

`python scripts/research_graph_diagram.py`도 Python 부재로 시작되지 않았다.
따라서 **docs/diagrams/research_graph.mmd는 생성하지 못했다.**
수동 노드·간선 목록이나 대체 렌더러를 실제 생성 결과로 제공하지 않았다.
생성 시도 기록은 `.runs/r17/diagram-attempt.txt`다. Python과 기존 의존성이 있는 게이트 환경에서
위 스크립트를 실행하여 생성 파일을 단일 작업 커밋에 포함해야 한다.
