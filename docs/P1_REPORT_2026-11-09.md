## 실행과 관찰

기존 가상환경의 Python 실행 파일이 sandbox 밖의 Python을 참조하여
일반 실행이 차단됐으므로, 승인된 권한에서 아래 시험을 한 번 실행했다.
패키지 설치나 `.env` 파일 접근은 하지 않았다.

```powershell
$env:PYTHONDONTWRITEBYTECODE='1'
$env:MEMVID_TELEMETRY='0'
$env:HF_HUB_OFFLINE='1'
$env:TRANSFORMERS_OFFLINE='1'
foreach ($taskKey in @('OPENAI_API_KEY','MEMVID_API_KEY','LANGSMITH_API_KEY','LANGCHAIN_API_KEY','LANGSMITH_TRACING','LANGCHAIN_TRACING_V2')) {
  Remove-Item -LiteralPath "Env:$taskKey" -ErrorAction SilentlyContinue
}
.\.venv\Scripts\python.exe -m pytest -q -rA --tb=short -p no:cacheprovider
```

기존 tracing 대조군의 가짜 endpoint `http://127.0.0.1:9`에 대한
LangSmith 연결 거부 경고가 출력됐다. 네트워크 시도 0회로 보고하지 않는다.
기존 tracing 관련 시험은 통과했다. 실제 외부 공급자나 LLM을 호출하는
새 코드는 추가하지 않았다.

시험 기대값·skip·기존 코드·데이터는 수정하지 않았다. `KNOWN_DEBT` 변경 없음.
착수 전부터 있던 미추적 `uv.lock`은 수정하거나 커밋하지 않았다.
보고서만 이 브랜치에 커밋·push하며 main 병합·push는 하지 않는다.
